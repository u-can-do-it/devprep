## Hints

- Is there still a `<Head>` component in the App Router, or is it something you export?
- How would the title of a product page include the product's name from the database?
- How do child pages inherit a "| My Shop" suffix from the root layout?

## Answer

The App Router uses the **Metadata API**. You export metadata from a `layout.tsx` or `page.tsx` (Server Components only), and Next.js renders the `<head>` tags.

**Static metadata:**

```tsx
// app/layout.tsx
import type { Metadata } from 'next';

export const metadata: Metadata = {
  metadataBase: new URL('https://shop.example.com'),
  title: { default: 'My Shop', template: '%s | My Shop' },
  description: 'Hand-made furniture',
};
```

**Dynamic metadata** with `generateMetadata`, which receives the same `params` as the page:

```tsx
// app/products/[id]/page.tsx
export async function generateMetadata({ params }: PageProps<'/products/[id]'>): Promise<Metadata> {
  const { id } = await params;
  const product = await getProduct(id); // deduplicated with the page's call via React.cache
  return {
    title: product.name, // -> "Oak Table | My Shop"
    description: product.summary,
    openGraph: { images: [product.imageUrl] },
    alternates: { canonical: `/products/${id}` },
  };
}
```

Metadata is **merged from the root down**: a child overrides the fields it sets and inherits the rest. `title.template` adds a suffix to child titles.

**File-based metadata** covers the rest:

- `opengraph-image.tsx` / `twitter-image.tsx` – OG images generated with `ImageResponse` from `next/og`
- `icon.png`, `apple-icon.png`, `favicon.ico`
- `sitemap.ts`, `robots.ts`, `manifest.ts`

Viewport and theme color go in a separate `viewport` export (or `generateViewport`).

**Follow-up:** you can't export `metadata` from a Client Component. Wrap the data call in `React.cache` so `generateMetadata` and the page don't hit the database twice.
