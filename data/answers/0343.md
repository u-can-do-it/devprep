## Hints

- In a compound index, should the field you sort by come before or after the field you filter by range?
- Why should `$match` appear as early as possible in a pipeline?
- How would you check whether a query used an index or scanned the whole collection?

## Answer

**Indexes** in MongoDB are B-trees, like in SQL databases. Without one, a query does a **COLLSCAN** (reads every document).

- Single-field, **compound**, **multikey** (indexes each array element), text, geospatial (`2dsphere`), TTL (auto-delete after a time), partial and unique indexes. Atlas also offers Search and Vector Search indexes.
- Compound index order follows the **ESR rule**: **E**quality fields first, then **S**ort fields, then **R**ange fields.

```js
// query: status = "paid", created in the last week, newest first
db.orders.createIndex({ status: 1, createdAt: -1, total: 1 });
db.orders.find({ status: "paid", total: { $gt: 100 } }).sort({ createdAt: -1 })
  .explain("executionStats"); // look for IXSCAN, and totalDocsExamined close to nReturned
```

**Aggregation pipeline** – documents flow through a sequence of stages, each transforming the stream (the MongoDB equivalent of `WHERE`, `GROUP BY`, `JOIN`, projections):

```js
db.orders.aggregate([
  { $match: { status: "paid", createdAt: { $gte: ISODate("2026-09-01") } } },
  { $group: { _id: "$customerId", revenue: { $sum: "$total" }, orders: { $sum: 1 } } },
  { $sort: { revenue: -1 } },
  { $limit: 10 },
  { $lookup: { from: "customers", localField: "_id", foreignField: "_id", as: "customer" } },
  { $unwind: "$customer" },
  { $project: { _id: 0, name: "$customer.name", revenue: 1, orders: 1 } },
]);
```

Performance tips:

- Put `$match` (and `$sort` + `$limit`) **first** – only early stages can use indexes, and filtering early shrinks the data.
- `$lookup` is a join; frequent heavy lookups suggest your schema should embed instead.
- Stages have memory limits; large sorts/groups may spill to disk (`allowDiskUse`).
- Every index slows writes and uses RAM – keep the working set of indexes in memory.
