## Hints

- How does the browser tell your page which color scheme the operating system uses?
- What should happen to native form controls and scrollbars in dark mode?
- How do you avoid a flash of the wrong theme when the user's choice is stored?

## Answer

**Dark mode**

1. Define colors as **custom properties** (design tokens), never hard-coded values.
2. Tell the browser which schemes you support, so native UI (form controls, scrollbars, the default canvas) adapts:

```css
:root {
  color-scheme: light dark;
  --bg: light-dark(#ffffff, #121212);
  --text: light-dark(#1a1a1a, #e8e8e8);
  --brand: light-dark(oklch(50% 0.2 260), oklch(75% 0.14 260));
}
body { background: var(--bg); color: var(--text); }
```

`light-dark()` picks a value based on the **used** `color-scheme`. Without it, you use the media query:

```css
@media (prefers-color-scheme: dark) {
  :root { --bg: #121212; --text: #e8e8e8; }
}
```

3. **Manual toggle:** store the choice (localStorage or a cookie) and set `color-scheme: light` or `dark` (or a `data-theme` attribute) on `<html>`.
   - Apply it **before first paint**, with a tiny inline script in `<head>` or by server-rendering it from a cookie. Otherwise users see a flash of the wrong theme.
   - Offer three options: light, dark and "system".

Dark-theme tips: avoid pure black, reduce saturation, check contrast again in both themes, and swap or dim images where needed (`<picture>` with `media="(prefers-color-scheme: dark)"`).

**Reduced motion**

Some users get dizzy or nauseous from motion (vestibular disorders). Respect their operating-system setting:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

A cleaner approach is to add motion only when it's allowed, with `@media (prefers-reduced-motion: no-preference)`. "Reduce" doesn't always mean "remove": replace slides and zooms with fades. In JavaScript, check `matchMedia('(prefers-reduced-motion: reduce)').matches`, for example before autoplaying a carousel or a view transition.

**Follow-up:** other preference queries include `prefers-contrast`, `forced-colors` (Windows High Contrast) and `prefers-reduced-transparency`.
