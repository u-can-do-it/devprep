## Hints

- What breaks in `` fetch(`/api/search?q=${query}`) `` when the user types `rock & roll`?
- How do you read the current page's `?page=2` without a router?
- Which inputs does `new FormData(form)` pick up, and which does it skip?
- Should you set `Content-Type` when the body is `FormData`?

## Answer

**`URLSearchParams`** builds and parses query strings and **encodes values for you**:

```js
const params = new URLSearchParams({ q: 'rock & roll', page: '2' });
params.append('tag', 'a');
params.append('tag', 'b');
fetch(`/api/search?${params}`);   // /api/search?q=rock+%26+roll&page=2&tag=a&tag=b
```

Building the string by hand, as in `` `?q=${query}` ``, breaks on `&`, `#`, `=` and spaces. If you must, at least use `encodeURIComponent(query)`.

**Reading and updating the current URL** without a router:

```js
const params = new URLSearchParams(window.location.search);
params.get('page');      // '2', or null when it's missing. Values are always strings
params.getAll('tag');    // ['a', 'b']
params.has('q');

params.set('page', '3');
params.delete('tag');
history.pushState(null, '', `?${params}`);   // updates the URL without reloading the page
```

**`URL`** handles a whole address:

```js
const url = new URL('/api/search', window.location.origin);
url.searchParams.set('q', 'react');
fetch(url);
```

**`FormData`** reads every field that has a **`name`** attribute:

```jsx
function SignupForm() {
  async function handleSubmit(e) {
    e.preventDefault();                                    // stop the full-page submit
    const data = new FormData(e.currentTarget);
    const values = Object.fromEntries(data);               // { email: '...', plan: 'pro' }

    await fetch('/api/signup', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(values),
    });
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="email" type="email" required />
      <select name="plan"><option>free</option><option>pro</option></select>
      <button>Sign up</button>
    </form>
  );
}
```

**Gotchas:**

- **Unchecked checkboxes aren't included.** Checked ones send `"on"` unless they have a `value`.
- Fields that repeat a name (multi-select, checkbox groups) need `data.getAll('name')`. `Object.fromEntries` keeps only the last value.
- Values are strings, or `File` objects for file inputs.

**Uploading files:** send the `FormData` itself as the body and **don't set `Content-Type`**. The browser sets `multipart/form-data` with the boundary:

```js
await fetch('/api/avatar', { method: 'POST', body: new FormData(form) });
```

**Classic form encoding** (`application/x-www-form-urlencoded`) is `body: new URLSearchParams(new FormData(form))`.

In React 19, `<form action={fn}>` passes a `FormData` straight to `fn` (#213).
