## Hints

- Does a user visiting the login page need the code for the admin dashboard?
- What does a dynamic `import()` return, and how do bundlers treat it?
- How can an image below the fold avoid being downloaded until it's needed?

## Answer

**Code splitting** breaks one large JS bundle into smaller chunks that load on demand. **Lazy loading** is deferring any resource (code, images, iframes) until it's actually needed. Both cut initial download, parse and execution time, improving LCP and INP.

**JavaScript:**

- **Route-based splitting** — each route is its own chunk. Next.js and most frameworks do this automatically.
- **Component-based splitting** — heavy components shown conditionally: modals, charts, editors, maps.

```jsx
import { lazy, Suspense } from 'react';

const Chart = lazy(() => import('./Chart')); // separate chunk

function Report({ showChart }) {
  return showChart && (
    <Suspense fallback={<Spinner />}>
      <Chart />
    </Suspense>
  );
}
```

In Next.js use `next/dynamic` (with `ssr: false` for browser-only libraries). For libraries, load on interaction: `const { format } = await import('date-fns')`. Prefetch chunks on hover or idle so the delay isn't noticeable.

**Images:**

```html
<img src="/photo.webp" loading="lazy" decoding="async"
     width="800" height="600" alt="Team photo"
     srcset="/photo-400.webp 400w, /photo-800.webp 800w"
     sizes="(max-width: 600px) 100vw, 800px">
```

- `loading="lazy"` for below-the-fold images and iframes; **never** on the LCP/hero image — use `fetchpriority="high"` there instead.
- Serve modern formats (AVIF/WebP) and responsive sizes via `srcset`/`sizes` or `<picture>`; always set dimensions to avoid CLS.
- `next/image` automates resizing, format conversion and lazy loading.

**Pitfalls:** splitting too finely creates request waterfalls; lazy-loading above-the-fold content hurts LCP; Suspense fallbacks can cause layout shift unless they reserve space. Analyze bundles with a bundle analyzer before and after.

**Follow-up:** tree shaking (removing unused exports) is complementary — it shrinks chunks, while splitting changes when they load.
