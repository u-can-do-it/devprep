## Hints

- How does a screen reader know which language and pronunciation to use?
- What happens to a layout that uses `margin-left` everywhere when the text runs right-to-left?
- Which parts of the UI should never be built by joining strings or putting text inside images?

## Answer

**Declare the language**

```html
<html lang="de">
  ...
  <p>Das nennt man <span lang="en">lazy loading</span>.</p>
```

`lang` drives screen reader pronunciation, hyphenation (`hyphens: auto`), quotation marks (`<q>`), spellcheck and font selection for CJK text. Change it on any inline phrase in another language. Use `<meta charset="utf-8">`.

**Support right-to-left scripts** (Arabic, Hebrew, Persian)

- Set `dir="rtl"` on `<html>` (`dir="ltr"` is the default).
- For user-generated content whose direction you don't know, use `dir="auto"` or `<bdi>`.
- Flexbox and Grid already follow the writing direction.

**Use CSS logical properties instead of physical ones**

```css
.card {
  margin-inline-start: 1rem;   /* not margin-left */
  padding-block: 0.5rem 1rem;  /* top / bottom */
  border-inline-end: 1px solid; /* not border-right */
  text-align: start;           /* not left */
  inset-inline-end: 0;         /* not right: 0 */
}
```

These flip automatically in RTL and work with vertical writing modes. Icons that show direction (arrows, "back") may need mirroring: `[dir="rtl"] .icon-back { transform: scaleX(-1); }`.

**Content and formatting**

- Use `Intl.DateTimeFormat`, `Intl.NumberFormat`, `Intl.PluralRules` and `Intl.RelativeTimeFormat` for locale-aware output instead of hand-made formatting.
- Use ICU message format (via i18next, FormatJS or next-intl) instead of joining sentence fragments. Word order and plurals differ between languages.
- Leave room for **text expansion**: German or Finnish strings can be 30% or more longer. Avoid fixed-width buttons.
- Keep text out of images.

**SEO**

Use separate URLs per locale (`/de/...`) and link them with `<link rel="alternate" hreflang="de" href="...">`, including `x-default`.

**Follow-up:** the `Accept-Language` header can suggest a starting locale, but always let users switch manually and remember their choice.
