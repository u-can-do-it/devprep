## Hints

- A user opens the app, switches to another app for three hours, and comes back. Did any component remount?
- A browser fires `focus` and `online` events on `window`. What replaces them in React Native?
- Does "connected to Wi-Fi" mean the internet is reachable?

## Answer

> The requests are the same `fetch` calls, but the environment differs. A mobile app isn't closed and reopened like a tab: it moves between foreground and background and can stay alive for days, so data goes stale without any remount. The network is slow, changes between Wi-Fi and cellular, and disappears. So you refetch when the app becomes active and when a screen gets focus, track connectivity with NetInfo, set timeouts, and show cached data first.

**What is different from the web**

- **No CORS and no browser cookies by default.** Requests go through the native network stack. Auth is usually a bearer token (#697).
- **No `window` focus or online events.** You wire the equivalents yourself.
- **Screens stay mounted** under other screens, so "fetch in `useEffect` on mount" runs once and never again (#674).
- **Plain HTTP is blocked** by default on both platforms. Use HTTPS, also in staging.
- **In development,** `localhost` on a device is the device itself. Use your computer's address, or `10.0.2.2` from the Android emulator.

**`AppState`**

`AppState.currentState` is `active`, `background` or (on iOS) `inactive`, which covers moments such as the app switcher or an incoming call.

**TanStack Query setup**

```tsx
import { AppState, Platform } from 'react-native';
import NetInfo from '@react-native-community/netinfo';
import { focusManager, onlineManager } from '@tanstack/react-query';

// 1. "Online" comes from NetInfo
onlineManager.setEventListener((setOnline) =>
  NetInfo.addEventListener((state) => setOnline(!!state.isConnected)),
);

// 2. "Window focus" comes from AppState
export function useAppFocusRefetch() {
  useEffect(() => {
    const sub = AppState.addEventListener('change', (status) => {
      if (Platform.OS !== 'web') focusManager.setFocused(status === 'active');
    });
    return () => sub.remove();
  }, []);
}
```

Now stale queries refetch when the user returns to the app, queries pause while offline, and paused mutations resume when the connection is back (#530).

**3. Screen focus**

```tsx
export function useRefetchOnScreenFocus(refetch: () => void) {
  const first = useRef(true);
  useFocusEffect(
    useCallback(() => {
      if (first.current) { first.current = false; return; }   // the mount already fetched
      refetch();
    }, [refetch]),
  );
}
```

Often it is simpler to invalidate the right queries after a mutation than to refetch on every focus.

**Network quality**

- `isConnected` means there is a network interface. `isInternetReachable` is closer to the truth, and a failed request is the final answer.
- Set a timeout with `AbortController`. A request on a weak cellular signal can hang for a long time.
- Retry idempotent requests with backoff. Don't retry a payment `POST` blindly (#356).
- Show an offline banner, and keep showing cached data instead of an error screen.

**Fast start**

Persist the query cache (`persistQueryClient` with MMKV or AsyncStorage, #681), so a cold start shows the last known data immediately and refreshes it in the background.

**Background and resume**

- JS stops soon after the app goes to the background. Timers and polling don't continue (#704).
- On return to the foreground: refetch stale data, reconnect WebSockets, and check that the token is still valid.

**Uploads and streaming**

- Upload a file with `FormData` and an object `{ uri, name, type }`, or with a native upload API that survives backgrounding.
- Streaming response bodies need a streaming-capable fetch implementation (for example `expo/fetch`); the classic React Native `fetch` returns the whole body at once.

**Follow-up:** users report seeing yesterday's prices after opening the app from the app switcher. What is missing? (A refetch on app focus. Connect `focusManager` to `AppState` and give the query a sensible `staleTime`.)
