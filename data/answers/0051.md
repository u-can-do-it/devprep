## Hints

- Do you need to control rows and columns at the same time, or just one direction?
- Should the content decide the layout, or should the layout decide where content goes?
- Which one would you pick for a navbar, and which for a whole page layout?

## Answer

**Flexbox is one-dimensional** — it lays items out along a single axis (a row or a column) and distributes space among them. It's **content-out**: item sizes drive the layout.

**Grid is two-dimensional** — you define rows and columns and place items into that structure. It's **layout-in**: the container defines the tracks, items fill them.

**Use Flexbox for:** navbars, toolbars, button groups, centering, aligning an icon with text, a list of tags that wraps, pushing an item to the end with `margin-left: auto`.

**Use Grid for:** page layouts, card galleries, forms with aligned labels, dashboards, anything where things must line up in both directions or overlap.

```css
/* Flex: toolbar */
.toolbar { display: flex; gap: 8px; align-items: center; }
.toolbar .spacer { flex: 1; }

/* Grid: responsive cards without media queries */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(240px, 1fr));
  gap: 16px;
}

/* Grid: page shell */
.page {
  display: grid;
  grid-template: "header header" auto "nav main" 1fr / 220px 1fr;
}
```

They combine well: a Grid page layout with Flexbox inside each component. Both support `gap` and the same alignment properties (`justify-content`, `align-items`).

**Gotcha:** with wrapping Flexbox, the last row's items don't align with the columns above — a sign you wanted Grid. **Subgrid** (supported in all modern browsers) lets nested elements align to the parent grid's tracks, e.g. card titles lining up across a row.

**Follow-up:** know `flex: 1` (= `1 1 0%`) and why `min-width: 0` fixes flex items overflowing with long text.
