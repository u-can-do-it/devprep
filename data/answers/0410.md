## Hints

- Why might you not want a 2 GB video upload to pass through your API servers?
- How can a client upload to a private bucket without having cloud credentials?
- What stops someone from reusing the URL forever or uploading a 50 GB file?

## Answer

A **presigned URL** is a URL to an object in object storage (S3, GCS, R2, Azure Blob) that contains a **signature, created with your server's credentials**, granting one specific operation (`PUT` or `GET`) on one specific key for a limited time. Anyone holding the URL can perform that operation until it expires. The bucket itself stays private.

**Upload flow:**
1. The client asks your API: "I want to upload `avatar.png` (image/png, 300 KB)".
2. The API **authenticates and authorizes** the user, validates type and size, picks the object key itself (e.g. `users/42/avatars/<uuid>.png`) and returns a presigned `PUT` URL valid for a few minutes.
3. The client uploads **directly to storage**, so your servers don't carry the bytes.
4. Storage fires an event (or the client confirms) and your backend records the file and post-processes it (virus scan, thumbnails).

```ts
import { S3Client, PutObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";

const s3 = new S3Client({});
const key = `users/${user.id}/avatars/${crypto.randomUUID()}.png`;
const url = await getSignedUrl(
  s3,
  new PutObjectCommand({ Bucket: "uploads", Key: key, ContentType: "image/png" }),
  { expiresIn: 300 },
);
```

**Downloads** work the same way: a short-lived presigned `GET` for private files (invoices, user documents), usually behind a CDN for public assets.

**Security notes:**
- Keep expiry short and never let the client choose the key.
- To enforce a max size, use a presigned **POST policy** with `content-length-range`, or check the size after upload.
- Configure bucket **CORS** for browser uploads.
- Treat uploaded content as untrusted: validate the real file type and serve it from a separate domain.
- For very large files, use **multipart upload** with a presigned URL per part.
