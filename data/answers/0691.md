**The screen**

```tsx
type Page = { items: Product[]; nextCursor: string | null };

function useDebounced<T>(value: T, ms = 300) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const t = setTimeout(() => setDebounced(value), ms);
    return () => clearTimeout(t);
  }, [value, ms]);
  return debounced;
}

export function ProductsScreen() {
  const [text, setText] = useState('');
  const search = useDebounced(text.trim());
  const [refreshing, setRefreshing] = useState(false);

  const q = useInfiniteQuery({
    queryKey: ['products', search],
    queryFn: ({ pageParam, signal }): Promise<Page> =>
      fetchProducts({ search, cursor: pageParam, signal }),      // signal cancels stale requests
    initialPageParam: null as string | null,
    getNextPageParam: (last) => last.nextCursor,
    placeholderData: keepPreviousData,                           // keep old rows while a new search loads
  });

  const items = useMemo(() => q.data?.pages.flatMap((p) => p.items) ?? [], [q.data]);

  const renderItem = useCallback(
    ({ item }: { item: Product }) => <ProductRow product={item} />,
    [],
  );

  const onRefresh = async () => {
    setRefreshing(true);
    try { await q.refetch(); } finally { setRefreshing(false); }
  };

  const loadMore = () => {
    if (q.hasNextPage && !q.isFetchingNextPage) q.fetchNextPage();
  };

  return (
    <View style={{ flex: 1 }}>
      <TextInput
        value={text}
        onChangeText={setText}
        placeholder="Search products"
        accessibilityLabel="Search products"
        autoCapitalize="none"
        autoCorrect={false}
        returnKeyType="search"
        clearButtonMode="while-editing"
      />

      {q.isPending ? (
        <ActivityIndicator style={{ flex: 1 }} />
      ) : q.isError && items.length === 0 ? (
        <ErrorState message="Couldn't load products" onRetry={() => q.refetch()} />
      ) : (
        <FlatList
          data={items}
          keyExtractor={(p) => p.id}
          renderItem={renderItem}
          refreshing={refreshing}
          onRefresh={onRefresh}
          onEndReached={loadMore}
          onEndReachedThreshold={0.5}
          ListEmptyComponent={<EmptyState text={`No results for "${search}"`} />}
          ListFooterComponent={
            q.isFetchingNextPage ? <ActivityIndicator /> :
            q.isFetchNextPageError ? <RetryRow onRetry={loadMore} /> : null
          }
          keyboardShouldPersistTaps="handled"
          keyboardDismissMode="on-drag"
          contentContainerStyle={items.length === 0 && { flexGrow: 1 }}
        />
      )}
    </View>
  );
}

const ProductRow = memo(function ProductRow({ product }: { product: Product }) {
  return (
    <View style={styles.row}>
      <Text numberOfLines={1}>{product.name}</Text>
      <Text>{formatPrice(product.price)}</Text>
    </View>
  );
});
```

**What to say while writing**

- **Debounce** the text, not the input: the field stays responsive, and the query key changes only after a pause.
- **The query key includes the search text,** so each search has its own cache and pages, and old responses can't overwrite new ones. The `signal` cancels requests that are no longer needed.
- **`onEndReached` can fire repeatedly,** so guard it with `hasNextPage` and `isFetchingNextPage`.
- **Separate `refreshing` state:** the pull-to-refresh spinner should show only for a user-initiated refresh, not for background refetches.
- **Errors:** a full-screen error only when there is nothing to show. A failure while loading more keeps the rows and shows a retry row in the footer.
- **Keyboard:** dragging the list closes it, and a tap on a row works on the first try.
- **Keys** are ids (#32), and the row is memoised (#673).

**Without TanStack Query**

Keep `items`, `cursor`, `status` and `error` in a reducer. Fetch in an effect that depends on `search`, with an `AbortController` aborted in the cleanup, so a slow response for "sho" can't replace the results for "shoes". Reset the list when the search changes. It's more code and more bugs, which is the argument for the library (#212).
