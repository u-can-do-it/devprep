## Hints

- In a row of cards, how do you get every card's footer to line up when the titles have different lengths?
- Can a grid item's children use the parent grid's tracks?
- How did people solve this before, and why was that fragile?

## Answer

Normally a grid only places its **direct children**. A grid item that is itself a grid creates **independent tracks**, so content in neighboring items can't line up.

**Subgrid** lets a nested grid **use its parent's tracks** on one or both axes (`grid-template-rows: subgrid` or `grid-template-columns: subgrid`). The child's children then sit on the parent's lines, and track sizes take everyone's content into account.

**Classic use: aligned card sections**

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr));
  gap: 1.5rem;
}
.card {
  display: grid;
  grid-row: span 3;              /* claim 3 of the parent's rows */
  grid-template-rows: subgrid;   /* use them for header / body / footer */
  gap: 0.5rem;                   /* override the inherited gap */
}
```

Now every card's title row is as tall as the **tallest** title in that row of cards, and all the footers line up, whatever the content length.

**Other uses:**

- Form layouts where labels and inputs in nested `<fieldset>`s share columns.
- Content inside a page wrapper that must align with the full page's column grid, including full-bleed breakouts.
- Nested lists or tables made from semantic markup but aligned like a table.

**Details:**

- Gaps are inherited from the parent but can be overridden.
- **Line names** are inherited, and you can add more.
- A subgridded axis has no implicit tracks of its own. The item must **span** the tracks it wants to use.

**Before subgrid:** fixed heights, JavaScript height-equalizing, `display: contents` (which removes the card's own box, so no background, border or semantics), or flattening the markup.

Subgrid has been supported in all major browsers since 2023.

**Follow-up:** container queries and subgrid work well together. Cards can adapt their own layout while still lining up with their siblings.
