## Hints

- Does the filtered list need its own `useState`?
- How do you delay a request until the user stops typing, using only `setTimeout`?
- What should the effect cleanup cancel: the timer, the request, or both?
- What happens if the user searches for `a&b`?

## Answer

**Part 1: filter a list that's already loaded.** The filtered list is **derived**, so compute it during render. Don't store it in state and sync it with an effect: that's the most common mistake here.

```jsx
function UserSearch({ users }) {
  const [query, setQuery] = useState('');

  const q = query.trim().toLowerCase();
  const visible = q ? users.filter((u) => u.name.toLowerCase().includes(q)) : users;

  return (
    <>
      <label>
        Search <input value={query} onChange={(e) => setQuery(e.target.value)} />
      </label>
      <p aria-live="polite">{visible.length} results</p>
      <ul>
        {visible.map((u) => <li key={u.id}>{u.name}</li>)}
      </ul>
    </>
  );
}
```

Wrap the filter in `useMemo` only if the list is large and the filter is measurably slow (#35).

**Part 2: search on the server, debounced.**

```jsx
function RemoteUserSearch() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);
  const [status, setStatus] = useState('idle');   // 'idle' | 'loading' | 'error'

  useEffect(() => {
    const q = query.trim();
    if (!q) { setResults([]); setStatus('idle'); return; }

    const controller = new AbortController();
    const timer = setTimeout(async () => {
      setStatus('loading');
      try {
        const res = await fetch(`/api/users?${new URLSearchParams({ q })}`, { signal: controller.signal });
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        setResults(await res.json());
        setStatus('idle');
      } catch (err) {
        if (err.name !== 'AbortError') setStatus('error');
      }
    }, 300);

    // typing again cancels the pending timer AND any request already in flight
    return () => {
      clearTimeout(timer);
      controller.abort();
    };
  }, [query]);

  return (
    <>
      <label>
        Search <input value={query} onChange={(e) => setQuery(e.target.value)} />
      </label>
      {status === 'loading' && <p>Searching…</p>}
      {status === 'error' && <p role="alert">Search failed.</p>}
      <ul>{results.map((u) => <li key={u.id}>{u.name}</li>)}</ul>
    </>
  );
}
```

**What to say out loud:**

- **Debounce** saves a request on every keystroke. Here it's done with `setTimeout` plus `clearTimeout` in the cleanup, with no library.
- **Race conditions:** without `abort()`, a slow response for "re" can arrive after the one for "react" and overwrite it.
- **Encoding:** `URLSearchParams` escapes `&`, spaces and so on (#515).
- **The input stays controlled and instant.** Only the *request* is delayed, not the typing.
