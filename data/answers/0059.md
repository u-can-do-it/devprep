## Hints

- What three things does a user care about: when the main content appears, whether the page reacts to input, and what else?
- Which metric replaced FID, and why was FID not enough?
- Why would lab tools like Lighthouse disagree with the numbers in Search Console?

## Answer

Core Web Vitals are Google's user-centric metrics, measured at the **75th percentile** of real-user page loads:

| Metric | Measures | Good |
|---|---|---|
| **LCP** — Largest Contentful Paint | Loading: when the largest image/text block renders | ≤ 2.5 s |
| **INP** — Interaction to Next Paint | Responsiveness: latency of interactions across the whole visit (roughly the worst) | ≤ 200 ms |
| **CLS** — Cumulative Layout Shift | Visual stability: unexpected layout movement | ≤ 0.1 |

INP replaced FID in March 2024 because FID only measured the *input delay* of the *first* interaction, ignoring processing and rendering time.

**Improving LCP** — break it into TTFB, resource load delay, load time and render delay:

- Fast server/CDN, caching, SSR/SSG so the HTML contains the content.
- Make the LCP image discoverable in the HTML (not lazy-loaded, not set by JS); `fetchpriority="high"`, preload; modern formats (AVIF/WebP), correct sizes.
- Remove render-blocking CSS/JS; preload fonts.

**Improving INP:**

- Break up **long tasks** (> 50 ms): yield with `scheduler.yield()` or `setTimeout`, defer non-urgent work.
- Ship less JS (code splitting, fewer third-party scripts), avoid heavy hydration.
- Keep event handlers light; show feedback immediately; use `startTransition` in React for expensive updates.
- Avoid layout thrashing and huge DOMs.

**Improving CLS:**

- Always set `width`/`height` or `aspect-ratio` on images, videos and iframes.
- Reserve space for ads, embeds and late-loading banners.
- Use `font-display: optional` or size-adjusted fallback fonts to avoid text reflow.
- Animate with `transform` instead of properties that move layout.

```html
<img src="/hero.avif" width="1200" height="600" fetchpriority="high" alt="...">
```

**Measuring:** field data (CrUX, Search Console, the `web-vitals` library sending to your analytics) is what counts; lab tools (Lighthouse, DevTools) are for debugging and can't measure INP without real interactions.

**Follow-up:** explain how you'd find the INP culprit — the Long Animation Frames (LoAF) API attributes slow frames to specific scripts.
