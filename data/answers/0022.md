## Hints

- Which of these reject as soon as one input fails, and which never reject?
- If you want the first *successful* response from several mirrors, which one fits?
- How would you build a request timeout with one of them?

## Answer

All four take an iterable of promises and return a single promise. They differ in **when they settle**:

| Method | Fulfills when | Rejects when | Result |
|---|---|---|---|
| `Promise.all` | **all** fulfill | **any** rejects (fail fast) | array of values, in input order |
| `Promise.allSettled` | **all** settle | never | array of `{status, value}` / `{status, reason}` |
| `Promise.race` | the **first one to settle** fulfills | the first one to settle rejects | that first value or reason |
| `Promise.any` | the **first one fulfills** | **all** reject | first value, or an `AggregateError` |

```js
// all: data that depends on every request
const [user, posts] = await Promise.all([getUser(), getPosts()]);

// allSettled: a dashboard where widgets may fail independently
const results = await Promise.allSettled(widgets.map(load));
const ok = results.filter(r => r.status === 'fulfilled').map(r => r.value);

// any: fastest healthy mirror
const data = await Promise.any(mirrors.map(url => fetch(url).then(r => r.json())));

// race: timeout
const timeout = (ms) => new Promise((_, rej) => setTimeout(() => rej(new Error('Timeout')), ms));
await Promise.race([fetch('/slow'), timeout(5000)]);
```

**Key points:**

- None of them **cancel** the losing or remaining promises. They keep running. For real cancellation, pass an `AbortSignal`. `AbortSignal.timeout(ms)` is the modern way to build a fetch timeout.
- With empty input: `all` and `allSettled` resolve to `[]`, `any` rejects, and `race` stays pending forever.
- `all` fails fast, so a single error hides the other results. Choose `allSettled` when you want partial results.

**Follow-up:** "Implement `Promise.all`" or "run promises with a concurrency limit".
