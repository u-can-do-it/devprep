## Hints

- How can the browser pick an image file before it knows the final layout?
- What's the difference between serving a smaller copy of the same image and serving a differently cropped one?
- How would you offer AVIF to browsers that support it and JPEG to the rest?

## Answer

These tools let the browser download **the smallest suitable image** instead of one huge file for every device.

**`srcset` with `x` descriptors** handles fixed-size images on screens with different pixel densities:

```html
<img src="logo.png" srcset="logo.png 1x, logo@2x.png 2x" width="120" height="40" alt="Acme">
```

**`srcset` with `w` descriptors plus `sizes`** handles fluid images:

```html
<img
  src="hero-800.jpg"
  srcset="hero-400.jpg 400w, hero-800.jpg 800w, hero-1600.jpg 1600w"
  sizes="(min-width: 1024px) 50vw, 100vw"
  width="1600" height="900" alt="Runner on a mountain trail">
```

`sizes` tells the browser how wide the image will be **displayed**. The browser needs this before CSS has loaded. It multiplies that width by the device pixel ratio and picks the closest candidate. If you leave `sizes` out, it defaults to `100vw`, which often over-downloads.

**`<picture>`** is for **art direction** (a different crop per breakpoint) and **format fallback**:

```html
<picture>
  <source media="(max-width: 600px)" srcset="hero-square.avif" type="image/avif">
  <source srcset="hero.avif" type="image/avif">
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" width="1600" height="900" alt="Runner on a mountain trail">
</picture>
```

The browser uses the first `<source>` that matches. The `<img>` is still required: it renders the image and holds `alt`, the dimensions and `loading`.

**Best practices:**

- Always set `width`/`height` or `aspect-ratio` to prevent layout shift.
- Use `loading="lazy"` below the fold, but never on the LCP image. Give the LCP image `fetchpriority="high"`.
- Generate the variants with an image CDN or a framework component (`next/image`).

**Follow-up:** `sizes="auto"` on lazy-loaded images lets the browser use the real layout width. Support is still limited, so keep a fallback list.
