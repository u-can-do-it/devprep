## Hints

- There is no `div` or `span`. What do you use for a box, and what for text?
- What happens if you put a bare string directly inside a `<View>`?
- Which component do you use for a tappable area, and how do you give feedback on press?

## Answer

> React Native has no HTML. You build screens from a small set of core components, and each one is backed by a real native view on iOS and Android. `View` is the box, `Text` shows text, `Image` shows pictures, `ScrollView` scrolls, `TextInput` takes input and `Pressable` handles touches. Every string must be inside `<Text>`, because a `View` is a plain native container that can't draw text.

| Component | Closest web element | iOS / Android view | Notes |
|---|---|---|---|
| `View` | `div` | `UIView` / `ViewGroup` | layout container, Flexbox, no text |
| `Text` | `span`, `p` | native text view | the only place text can live; can be nested |
| `Image` | `img` | `UIImageView` / `ImageView` | remote images need a width and height (#672) |
| `ScrollView` | `overflow: scroll` | `UIScrollView` / `ScrollView` | renders all children at once (#669) |
| `TextInput` | `input`, `textarea` | `UITextField` / `EditText` | `onChangeText`, keyboard props (#680) |
| `Pressable` | `button` | a view with touch handling | `onPress`, `onLongPress`, pressed state |

Others you use often: `FlatList` and `SectionList` (virtualised lists), `Modal`, `Switch`, `ActivityIndicator`, `RefreshControl`, `KeyboardAvoidingView` and `StatusBar`.

**Why text must be in `<Text>`**

A `View` maps to a native container that has no idea how to measure or draw characters. So this throws "Text strings must be rendered within a `<Text>` component":

```tsx
<View>Hello</View>                 // error
<View>{count && <Badge />}</View>  // error when count is 0: the 0 is a bare string (#195)
<View><Text>Hello</Text></View>    // ok
```

Text styles (`color`, `fontSize`, `fontFamily`) don't inherit from a `View`. They inherit only from a parent `Text` to a nested `Text`:

```tsx
<Text style={{ fontSize: 16 }}>
  Total: <Text style={{ fontWeight: 'bold' }}>120 PLN</Text>
</Text>
```

**Handling touches**

```tsx
<Pressable
  onPress={save}
  hitSlop={8}                                   // bigger touch area than the visible one
  android_ripple={{ color: '#0002' }}
  style={({ pressed }) => [styles.button, pressed && styles.pressed]}
  accessibilityRole="button"
>
  <Text>Save</Text>
</Pressable>
```

- There is no `onClick` and no hover. The event is `onPress`.
- `Pressable` is the current API. `TouchableOpacity` and `TouchableHighlight` are older and still common in codebases. `Button` is a basic platform-styled button with almost no styling options.
- A plain `View` isn't tappable. Wrap it in a `Pressable`.

**Things that surprise web developers**

- No `className`, no CSS files, no cascade (#668).
- A `View` doesn't scroll when content overflows. You need a `ScrollView` or a list.
- The default layout direction is a column, not a row.
- Core `SafeAreaView` is deprecated. Use `react-native-safe-area-context` (#679).

**Follow-up:** you need a row with an icon and a label where the whole row is tappable and a screen reader reads it as one button. How do you build it? (One `Pressable` with `accessibilityRole="button"` and a label, with the `Image` and `Text` inside; see #689.)
