## Hints

- If the intervals are sorted by start time, how do you know whether the next one overlaps the last merged one?
- Do `[1, 3]` and `[3, 5]` overlap? Ask the interviewer.
- Free time is the gaps between merged busy intervals.
- For meeting rooms: what if you treat every start as +1 and every end as −1?

## Answer

Nearly every interval problem starts with **sorting by start time**. After that, one pass is enough.

**Merge overlapping intervals:**

```js
function merge(intervals) {
  const sorted = intervals.toSorted((a, b) => a[0] - b[0]);
  const merged = [];
  for (const [start, end] of sorted) {
    const last = merged.at(-1);
    if (last && start <= last[1]) last[1] = Math.max(last[1], end); // overlaps or touches
    else merged.push([start, end]);                                  // new array: input isn't mutated
  }
  return merged;
}

merge([[1, 3], [8, 10], [2, 6], [15, 18]]); // [[1, 6], [8, 10], [15, 18]]
```

**Free slots shared by several calendars:** merge everyone's busy time, then walk the gaps.

```js
function freeSlots(calendars, dayStart, dayEnd, minLength = 1) {
  const free = [];
  let cursor = dayStart;
  for (const [start, end] of merge(calendars.flat())) {
    if (start >= dayEnd) break;
    if (start - cursor >= minLength) free.push([cursor, start]);
    cursor = Math.max(cursor, end);
  }
  if (dayEnd - cursor >= minLength) free.push([cursor, dayEnd]);
  return free;
}

// times in minutes from midnight: 9:00 = 540
freeSlots([[[540, 600], [720, 780]], [[570, 660]]], 540, 1020, 30);
// [[660, 720], [780, 1020]]  -> 11:00-12:00 and 13:00-17:00
```

**Minimum number of meeting rooms** with a sweep line:

```js
function roomsNeeded(meetings) {
  const events = meetings
    .flatMap(([s, e]) => [[s, 1], [e, -1]])
    .sort((a, b) => a[0] - b[0] || a[1] - b[1]); // at the same time, ends (-1) come before starts
  let rooms = 0, max = 0;
  for (const [, delta] of events) max = Math.max(max, (rooms += delta));
  return max;
}
```

**Complexity:** O(n log n) for the sort, then O(n). O(n) space.

**Variants you might get:** insert a new interval into a sorted list, check whether a new meeting conflicts, find the intersection of two interval lists (two pointers), or find the point covered by the most intervals.

**Clarify first:** are the intervals inclusive or half-open? Are times strings (`"09:30"`) that you need to convert to minutes? Is the input already sorted?
