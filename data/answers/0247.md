## Hints

- Does an internal admin panel behind a login need SSR or SEO?
- How much JavaScript does a mostly static marketing or docs site really need?
- What does your team give up in simplicity and hosting freedom when it adopts RSC, Server Actions and framework caching?

## Answer

Next.js is a strong default for **public, content-plus-app products** that need SEO, fast first loads and a backend-for-frontend layer. It's not free, though, and a senior engineer should be able to argue against it.

**When it may be the wrong choice:**

- **Pure SPAs behind a login** (dashboards, internal tools, editors): no SEO need, mostly client state. **Vite + React Router or TanStack Router** is simpler, deploys as static files, and has no server/client boundary to reason about.
- **Content-heavy, low-interactivity sites** (docs, blogs, marketing): **Astro** (islands) ships far less JS by default. A static site generator may be enough.
- **Backend-heavy systems**: long-running jobs, WebSockets, queues, complex domain logic. Next.js isn't a general backend. Keep a dedicated service (Node/NestJS, FastAPI, Go) and use Next.js only as a BFF, or not at all.
- **Hosting constraints**: only static hosting or a CDN available. `output: 'export'` loses Server Actions, ISR, proxy and on-demand image optimization.
- **Team or org fit**: a team that doesn't know React, a non-React stack (Vue → Nuxt, Svelte → SvelteKit), or micro-frontends owned by many teams.
- **Stability needs**: the App Router's caching model changed across 13 → 14 → 15 → 16. If you want few framework upgrades, that churn is a real cost.

**Trade-offs to state honestly:**

- More concepts: RSC boundaries, multiple cache layers, `'use cache'`, PPR, proxy.
- Some features are smoothest on Vercel. Self-hosting at scale needs extra work (shared cache handler, encryption key, version skew), although the Adapter API is improving portability.
- Server costs and cold starts versus purely static hosting.

**Credible alternatives:** React Router v7 framework mode (formerly Remix), TanStack Start, Astro, Vite SPA, SvelteKit, Nuxt.

**Follow-up:** interviewers want to hear that you decide based on requirements (SEO, interactivity, team, hosting, budget), not hype. Mention a case where you chose, or would choose, something else.
