## Hints

- How do you tell the type checker that `first(xs)` returns the same type as the list elements?
- What did you need to import before Python 3.12 to declare a type variable?
- How do you restrict a type variable to types with certain methods, or to a fixed set of types?

## Answer

Generics let a function or class be written once and keep **precise types** for each use.

**Python 3.12+ syntax (PEP 695)**: type parameters go in square brackets, with no `TypeVar` boilerplate.

```python
from collections.abc import Callable, Hashable, Iterable

def first[T](items: Iterable[T]) -> T | None:
    return next(iter(items), None)

first([1, 2])        # inferred as int | None

def group_by[T, K: Hashable](items: Iterable[T], key: Callable[[T], K]) -> dict[K, list[T]]:
    ...                                    # K is bounded

def to_num[N: (int, float)](x: N) -> N:    # constrained to int OR float
    ...

class Repository[ModelT]:
    def get(self, id: int) -> ModelT | None: ...
    def add(self, obj: ModelT) -> None: ...

class UserRepo(Repository[User]): ...

type Pair[T] = tuple[T, T]                 # generic type alias
type JSON = dict[str, JSON] | list[JSON] | str | int | float | bool | None
```

The older equivalent, still common in existing code:

```python
from typing import TypeVar, Generic
T = TypeVar("T")
class Repository(Generic[T]): ...
```

Related concepts:

- **Bounds** (`K: Hashable`) vs **constraints** (`N: (int, float)`).
- **ParamSpec** (`[**P]`) for decorators that keep the wrapped function's signature, and **TypeVarTuple** (`[*Ts]`) for variadic generics.
- **Variance** is inferred automatically with the new syntax.
- Python 3.13 adds **defaults** for type parameters (`class Box[T = int]`).
- Annotations aren't enforced at runtime. A checker (mypy, pyright) or a validator (Pydantic) does the work. In 3.14, annotations are evaluated lazily (PEP 649), so forward references no longer need quotes.

**Follow-up:** How would you type a decorator so the decorated function keeps its parameters? (`def deco[**P, R](fn: Callable[P, R]) -> Callable[P, R]`.)
