## Hints

- What should be returned for an empty input?
- How do you keep results in the original order when promises resolve out of order?
- When should the returned promise reject, and what about non-promise values in the input?

## Answer

Requirements to state up front:

- Accept any **iterable**.
- Resolve with the results **in input order**.
- **Reject as soon as any input rejects** (with that first reason).
- Treat plain values like resolved promises.
- Resolve immediately with `[]` for an empty input.

```js
function promiseAll(iterable) {
  return new Promise((resolve, reject) => {
    const items = Array.from(iterable);
    const results = new Array(items.length);
    let remaining = items.length;

    if (remaining === 0) return resolve([]);

    items.forEach((item, i) => {
      Promise.resolve(item).then(
        (value) => {
          results[i] = value;          // keep the original order
          if (--remaining === 0) resolve(results);
        },
        reject,                         // first rejection wins; later calls are ignored
      );
    });
  });
}

await promiseAll([1, Promise.resolve(2), fetchThree()]); // [1, 2, 3]
```

**Points the interviewer looks for:**

- **Count completions** instead of checking `results.length`. Assigning `results[i]` out of order already makes the length full.
- `Promise.resolve(item)` handles plain values and thenables.
- Settling a promise twice is a no-op, so calling `reject` many times is safe.
- **No cancellation:** the other operations keep running after a rejection. Mention `AbortController` if cancellation is needed.

**Variations to expect:**

- **`allSettled`:** never reject. Store `{ status: 'fulfilled', value }` or `{ status: 'rejected', reason }`.
- **Concurrency limit:** run at most N at a time with a worker pool:

```js
async function mapLimit(items, limit, fn) {
  const out = []; let next = 0;
  const worker = async () => { while (next < items.length) { const i = next++; out[i] = await fn(items[i]); } };
  await Promise.all(Array.from({ length: Math.min(limit, items.length) }, worker));
  return out;
}
```

**Follow-up:** also implement `Promise.race` and `Promise.any`. `any` rejects with an `AggregateError`.
