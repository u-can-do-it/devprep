## Hints

- What's the difference between `ReactNode` and `JSX.Element` as a type for `children`?
- How can a `Button` wrapper accept every native `<button>` attribute without listing them all?
- What type does `e` have in an `onChange` handler for an `<input>`?

## Answer

**Props:** use a `type` or `interface` and destructure. Defaults go in the destructuring, not in `defaultProps`:

```tsx
type CardProps = {
  title: string;
  variant?: 'primary' | 'ghost';
  children: React.ReactNode;          // anything renderable
  onClose?: () => void;
};

function Card({ title, variant = 'primary', children, onClose }: CardProps) { ... }
```

**`children`:** use `React.ReactNode`, which covers elements, strings, numbers, `null` and arrays. `JSX.Element` is too narrow. Use `React.ReactElement` only if you truly need a single element.

**Extending native elements:** reuse the DOM types instead of retyping them:

```tsx
type ButtonProps = React.ComponentProps<'button'> & { loading?: boolean };

function Button({ loading, children, ...rest }: ButtonProps) {
  return <button {...rest} disabled={loading || rest.disabled}>{children}</button>;
}
```

In React 19, `ComponentProps<'button'>` already includes `ref`, because ref is a regular prop. Use `ComponentProps<typeof MyComponent>` to extract another component's props.

**Events:**

```tsx
const onChange = (e: React.ChangeEvent<HTMLInputElement>) => setName(e.target.value);
const onSubmit = (e: React.FormEvent<HTMLFormElement>) => { e.preventDefault(); };
// for a callback prop:  onSelect: (id: string) => void
```

Inline handlers infer their types automatically. You only need these types when you extract the handler.

**Hooks:** `useState<User | null>(null)`, `useRef<HTMLDivElement>(null)`, and discriminated unions for reducer actions.

**Notes:** `React.FC` is acceptable again because it no longer adds implicit `children`, but plain typed functions are more common. Use `React.JSX` instead of the global `JSX` namespace.

**Follow-up:** for generic components like `<List<T> items={T[]} renderItem={(t: T) => ...} />`, write the function with a type parameter.
