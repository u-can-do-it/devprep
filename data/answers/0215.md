## Hints

- Why do developers wrap things in `useMemo` and `useCallback` by hand, and what goes wrong when they forget a dependency?
- At what point does the compiler run: in the browser, or at build time?
- What must your code follow for automatic memoization to be safe?

## Answer

The **React Compiler** (stable since v1.0, October 2025) is a **build-time** tool, delivered as a Babel plugin and integrated into Next.js, Vite and Expo. It analyzes components and hooks and **inserts memoization automatically**. It caches JSX, computed values and callbacks so that unchanged parts don't recompute or re-render. It's roughly what perfect `useMemo`/`useCallback`/`React.memo` usage would give you, but at a finer level. It can memoize after an early return or inside conditionals, which hand-written hooks can't.

```jsx
// You write:
function List({ items, filter }) {
  const visible = items.filter(i => i.tag === filter);
  return <Rows items={visible} onSelect={id => track(id)} />;
}
// The compiler caches `visible`, the callback and the <Rows> element,
// and reuses them while `items` and `filter` are unchanged.
```

**What changes for developers:**

- New code mostly **doesn't need manual memoization**. Leave existing `useMemo` and `useCallback` in place. They remain valid, and they're still useful as precise control, for example when a value is an effect dependency.
- Your code must follow the **Rules of React**: pure render, no mutation of props or state, no reading or writing refs during render, and hooks rules. Where the compiler detects a violation, it **skips** that component instead of breaking it. The `eslint-plugin-react-hooks` compiler rules show you where.
- You can opt in gradually per directory, and opt a component out with the `"use no memo"` directive.

**What it doesn't fix:** expensive work that really must rerun, Context fan-out (every consumer of a changed value still re-renders), huge lists (use virtualization), slow network, or bundle size.

**Follow-up:** check its effect with React DevTools. Compiled components show a "Memo ✨" badge. Measure with the Profiler before and after.
