## Hints

- When does a Sass variable get its value, and when does a CSS custom property?
- Can JavaScript or a media query change a Sass variable while the page is running?
- Which Sass features have native CSS equivalents now, and which don't?

## Answer

**Sass variables are compile-time. Custom properties are runtime.**

| | Sass `$var` | CSS `--var` |
|---|---|---|
| Resolved | At build time, then disappears | In the browser, live |
| Scope | Lexical (by file or block) | **Cascade and inheritance** through the DOM |
| Change at runtime | No | Yes: by selector, media query, or `el.style.setProperty()` |
| Readable from JS | No | `getComputedStyle(el).getPropertyValue('--brand')` |
| Usable in media query conditions | Yes | **No** (`@media (min-width: var(--bp))` doesn't work) |
| Crosses Shadow DOM | n/a | Yes, so it's the way to theme web components |

```css
:root { --brand: oklch(55% 0.2 260); --radius: 0.5rem; }
[data-theme="dark"] { --brand: oklch(75% 0.15 260); }

.button {
  background: var(--brand);
  border-radius: var(--radius);
  padding: var(--button-padding, 0.5rem 1rem); /* fallback */
}
.button.compact { --button-padding: 0.25rem 0.5rem; }
```

This makes custom properties the base for **design tokens, theming and dark mode**. One component reads variables, and its context sets them.

**Do you still need Sass in 2026?** Usually not for new projects. Native CSS now covers most of what people used it for:

- **Nesting** with `&`
- **Color functions**: `color-mix()`, relative color syntax (`oklch(from var(--brand) calc(l + 10%) c h)`)
- **Math**: `calc()`, `clamp()`, `round()`, trigonometric functions
- **Imports into layers** with `@import ... layer()`, and scoping with `@scope` and `@layer`
- **Typed, animatable variables** with `@property`

Sass still helps with **loops and maps** (generating utility classes), **mixins and functions**, and large legacy codebases. PostCSS or Lightning CSS handle bundling, minification and down-levelling. Tailwind v4 is built on native custom properties.

**Gotcha:** native nesting doesn't concatenate selectors. `&__title` (the BEM trick) only works in Sass.

**Follow-up:** an undefined `var()` without a fallback makes the declaration "invalid at computed-value time". The property falls back to its inherited or initial value, not to the previous rule.
