## Hints

- Which FastAPI class extracts the `Bearer` token from the `Authorization` header and wires up the "Authorize" button in `/docs`?
- What must you verify when decoding a JWT, and what should never go into its payload?
- How do you protect a whole router, not just one endpoint?

## Answer

Flow: the client posts credentials to a **token endpoint**, receives a signed JWT, and sends it as `Authorization: Bearer <token>`. A **dependency** validates the token and loads the user.

```python
from datetime import datetime, timedelta, timezone
from typing import Annotated
import jwt                                   # PyJWT
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")
app = FastAPI()

@app.post("/token")
async def login(form: Annotated[OAuth2PasswordRequestForm, Depends()]):
    user = await users.get_by_email(form.username)
    if not user or not password_hash.verify(form.password, user.password_hash):
        raise HTTPException(401, "Incorrect credentials")
    exp = datetime.now(timezone.utc) + timedelta(minutes=15)
    token = jwt.encode({"sub": str(user.id), "exp": exp}, settings.jwt_secret, algorithm="HS256")
    return {"access_token": token, "token_type": "bearer"}

async def current_user(token: Annotated[str, Depends(oauth2_scheme)]):
    unauthorized = HTTPException(401, "Invalid token", headers={"WWW-Authenticate": "Bearer"})
    try:
        payload = jwt.decode(token, settings.jwt_secret, algorithms=["HS256"])
    except jwt.InvalidTokenError:
        raise unauthorized
    user = await users.get(int(payload["sub"]))
    if user is None or not user.is_active:
        raise unauthorized
    return user

CurrentUser = Annotated[User, Depends(current_user)]

@app.get("/me")
async def me(user: CurrentUser):
    return user
```

Key points:

- **Pin `algorithms`** when decoding (prevents `alg: none` and algorithm-confusion attacks). Verify `exp`, plus `aud`/`iss` if you use them.
- Hash passwords with **Argon2 or bcrypt** (the FastAPI docs use `pwdlib` with Argon2).
- The payload is only **encoded, not encrypted**: no secrets or PII in it.
- Keep access tokens short-lived and use refresh tokens (rotated, revocable) for long sessions. Use RS256/ES256 with JWKS when other services verify the tokens.
- Protect groups of routes with `APIRouter(dependencies=[Depends(current_user)])`. Add role checks as dependencies built on `current_user`, or with `Security` scopes.
- For browser apps, consider httpOnly cookies, or delegate to an identity provider (OIDC).

**Follow-up:** How would you revoke a JWT before it expires? (A deny-list keyed by `jti`, a per-user token version, or very short expiry plus refresh-token revocation.)
