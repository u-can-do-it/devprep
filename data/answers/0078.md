## Hints

- What does FastAPI do with a parameter declared as `db = Depends(get_db)` before calling your endpoint?
- When, relative to the response, does the code after `yield` in a dependency run?
- How would you replace a real dependency with a fake one in tests?

## Answer

`Depends` declares that an endpoint (or another dependency) needs a value produced by some callable. On each request FastAPI resolves the **dependency graph**: calls the dependency with its own parameters (query, headers, other dependencies), and injects the result. Dependencies are **cached per request**, so one used in several places runs once.

```python
from typing import Annotated
from fastapi import Depends, FastAPI, Header, HTTPException

app = FastAPI()

async def get_db():
    session = SessionLocal()
    try:
        yield session            # value injected
    finally:
        await session.close()    # runs after the endpoint returns but BEFORE the response is sent (FastAPI 0.106+);
                                 # Depends(get_db, scope="request") (0.118+) runs it after the response instead

DB = Annotated[AsyncSession, Depends(get_db)]

async def current_user(db: DB, authorization: str = Header()):
    user = await verify_token(db, authorization)
    if not user:
        raise HTTPException(401)
    return user

@app.get("/me")
async def me(user: Annotated[User, Depends(current_user)]):
    return user
```

Key features:

- **`yield` dependencies** for setup/teardown (DB sessions, transactions).
- **`Annotated` aliases** for reuse and clean signatures (recommended style).
- **Router- or app-level dependencies**: `APIRouter(dependencies=[Depends(require_admin)])`.
- **Class dependencies** and parameterized ones (a callable that returns a dependency).
- **Testing**: `app.dependency_overrides[get_db] = fake_db`.

Why it matters: separation of concerns (auth, DB, pagination), less duplication, and dependencies are reflected in OpenAPI (e.g. security schemes).
