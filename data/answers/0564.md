## Hints

- Is `var x = 5;` statically typed? What type does the compiler see?
- With `object`, what do you have to do before calling a method of the real type?
- When is a member call on `dynamic` checked: at compile time or at run time?

## Answer

| | `var` | `object` | `dynamic` |
|---|---|---|---|
| What it is | compile-time **type inference** | the base type of everything | "skip compile-time checks" |
| Static type | the inferred type (`int`, `List<User>`) | `object` | `dynamic` (really `object` + runtime binding) |
| Member calls checked | at compile time | at compile time, only `object` members | at **run time** |
| Value types | not boxed | **boxed** (#562) | boxed |
| IntelliSense | full | only `object` members | none |

**`var`** is just shorthand: the compiler infers the type from the right-hand side, and the variable is **as strongly typed** as if you wrote the type. It works only for local variables with an initializer.

```csharp
var count = 5;              // int
var users = new List<User>();
count = "five";             // compile error: count is an int
var x;                      // compile error: nothing to infer from
var n = null;               // compile error
```

Use it when the type is obvious from the right side or the name is long; write the type when it's not obvious (`var result = Calculate();`). It's a style choice, not a performance one.

**`object`** can hold anything, but you can only use `object` members until you cast. Casting checks the type at run time:

```csharp
object o = "hello";
int len = ((string)o).Length;   // explicit cast
if (o is string s) len = s.Length;   // safer: pattern matching (#580)
```

**`dynamic`** turns off compile-time checking. Member calls are resolved at **run time** by the DLR; a typo compiles fine and throws `RuntimeBinderException` when it runs. It's also slower (runtime binding, with caching).

```csharp
dynamic d = "hello";
int len = d.Length;     // resolved at run time
d.Lenght();             // compiles, fails at run time
```

Legitimate uses: COM/Office interop, interop with dynamic languages, and some reflection-heavy code. For JSON, prefer typed models or `JsonElement`/`JsonNode` over `dynamic`.

**Follow-up:** does `var` slow anything down? (No. It's resolved at compile time; the IL is identical to writing the type.)
