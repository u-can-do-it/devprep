## Hints

- Does a class have to inherit from something to satisfy each one?
- When are the checks performed: at instantiation, at type-check time, or with `isinstance`?
- Which one lets you describe a third-party class you can't modify?

## Answer

Both describe "an object that has these methods", but they differ in **how a class qualifies**.

**ABC: nominal subtyping.** A class must **explicitly inherit** from the ABC. Python enforces it at runtime: you can't instantiate a subclass until all `@abstractmethod`s are implemented. ABCs can also hold shared concrete methods.

```python
from abc import ABC, abstractmethod

class PaymentGateway(ABC):
    @abstractmethod
    def charge(self, cents: int) -> str: ...

    def refund_all(self, ids):            # shared implementation
        return [self.refund(i) for i in ids]

class Stripe(PaymentGateway): ...
Stripe()   # TypeError: can't instantiate abstract class
```

**Protocol: structural subtyping** (static duck typing). Any class with matching methods **automatically conforms**, with no inheritance needed. It's checked by mypy or pyright, not at runtime.

```python
from typing import Protocol

class SupportsClose(Protocol):
    def close(self) -> None: ...

def shutdown(resources: list[SupportsClose]) -> None:
    for r in resources:
        r.close()

shutdown([open("f.txt"), socket_obj, my_pool])   # all fine, none inherit
```

When to choose:

- **Protocol** for **dependency boundaries** (repositories, clients, callbacks), for types from code you don't own, and to keep modules decoupled. It's TypeScript-style typing and the most common modern choice.
- **ABC** when you own a class hierarchy, want **runtime enforcement**, or want to share implementation (template method pattern). Plugin systems are a common example.

`@runtime_checkable` allows `isinstance(x, SupportsClose)`, but it only checks that the methods **exist**, not their signatures.

**Follow-up:** How do protocols make testing easier? (Any simple fake with the right methods type-checks. No subclassing or mocking framework needed.)
