## Hints

- When you navigate between two pages that share a layout, does the layout re-mount?
- Where would you put an enter animation that should replay on every page change?
- What happens to `useState` inside each one on navigation?

## Answer

Both wrap child segments and receive `children`. The difference is **what happens on navigation**:

| | `layout.tsx` | `template.tsx` |
|---|---|---|
| On navigation between children | **Persists**: no re-mount, no re-render | **Re-mounts**: a new instance per navigation |
| Client state in it (`useState`) | Kept | Reset |
| Effects (`useEffect`) | Run once | Run again on each navigation |
| DOM | Reused | Recreated |
| Suspense fallbacks inside | Shown only the first time | Shown again on each navigation |

Under the hood, Next.js renders the template with a **unique `key` per route**, so React treats each navigation as a new component:

```tsx
<Layout>
  <Template key={routeParam}>{children}</Template>
</Layout>
```

**Use a layout (the default choice) for:** navigation bars, sidebars, providers, and anything that should keep state and avoid extra work. Persistent layouts are a big reason App Router navigations are fast.

**Use a template when you need per-navigation behavior:**

- Enter/exit animations that replay on each page (although React's `<ViewTransition>` is now often the better tool)
- Logging page views with `useEffect`
- Resetting a form or a feedback widget whenever the route changes
- Showing a Suspense fallback on every navigation instead of only the first

```tsx
// app/(shop)/template.tsx
'use client';
import { useEffect } from 'react';

export default function Template({ children }: { children: React.ReactNode }) {
  useEffect(() => { analytics.pageView(location.pathname); }, []);
  return <div className="fade-in">{children}</div>;
}
```

**Follow-up:** a layout doesn't re-render on navigation, so it can't rely on the current pathname or `searchParams` in a Server Component. Layouts don't even receive `searchParams`. Use a client hook like `usePathname()` in a small child component.
