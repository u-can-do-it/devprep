## Hints

- When you click a button inside a `div`, in what order do the listeners on `document`, the `div` and the button run?
- How can one listener on a parent handle clicks on 1,000 list items, including ones added later?
- What's the difference between `event.target` and `event.currentTarget`?

## Answer

A DOM event travels in **three phases**:

1. **Capturing:** from `window` down through the ancestors to the target.
2. **Target:** at the element where the event happened.
3. **Bubbling:** from the target back up to `window`.

`addEventListener(type, fn)` listens in the bubbling phase by default. Pass `{ capture: true }` to listen during capturing. Some events don't bubble (`focus`, `blur`, `mouseenter`). Their bubbling versions are `focusin`/`focusout`.

**Event delegation:** put one listener on a common ancestor and use `event.target` to find which child was involved.

```js
document.querySelector('#todo-list').addEventListener('click', (e) => {
  const btn = e.target.closest('button[data-action="delete"]');
  if (!btn || !e.currentTarget.contains(btn)) return;
  removeTodo(btn.closest('li').dataset.id);
});
```

**Benefits:**

- One listener instead of N, so less memory and less setup work.
- It works for elements **added later**, so you don't need to re-attach listeners after re-rendering.

**Useful APIs:**

- `event.target` is the element that started the event. `event.currentTarget` is the element whose listener is running now.
- `e.stopPropagation()` stops the event from moving further. `stopImmediatePropagation()` also skips the other listeners on the same element.
- `e.preventDefault()` cancels the default action (following a link, submitting a form). It is unrelated to propagation.
- Pass `{ passive: true }` for scroll and touch listeners that never call `preventDefault`.

**Pitfalls:** use `closest()` because the click target may be a nested `<span>` or icon. Avoid overusing `stopPropagation`, since it breaks delegated handlers such as analytics. React attaches its events to the root container, which is delegation as well.
