## Hints

- What does `s += "x"` actually do to the original string?
- How many strings does a loop of 10,000 `+=` create?
- Why is `a.ToLower() == b.ToLower()` a poor way to compare case-insensitively?

## Answer

**Immutability:** a `string` can't be changed after it's created. Every "modification" (`+`, `Replace`, `ToUpper`, `Substring`) returns a **new** string. Benefits: strings are safe to share between threads, safe as dictionary keys (the hash can't change), and literals can be **interned** (one shared instance per literal).

```csharp
string s = "abc";
s.ToUpper();          // result is thrown away; s is still "abc"
s = s.ToUpper();      // s now points to a new string "ABC"
```

**`StringBuilder`:** a mutable buffer. Use it when you build a string in a **loop** or many steps. `+=` in a loop copies the whole string each time (quadratic work); `StringBuilder` appends into a growing buffer.

```csharp
var sb = new StringBuilder();
foreach (var line in lines) sb.Append(line).Append('\n');
string result = sb.ToString();
```

For a few concatenations, plain `+` or interpolation (`$"{a} {b}"`) is fine and clearer; the compiler already optimises it. `string.Join` and `string.Concat` are better for collections.

**Equality:**

- `==` on two `string`s compares **contents** (string overloads the operator), not references.
- `a.Equals(b)` also compares contents; it throws `NullReferenceException` if `a` is `null`. `string.Equals(a, b)` is null-safe.
- Watch out: if one side is typed as `object`, `==` compares **references**: `(object)a == (object)b` can be `false` for equal text.

**Comparison options:** the default `Equals` is **ordinal** (exact UTF-16 code units). Say what you mean with `StringComparison`:

| Option | Use for |
|---|---|
| `Ordinal` | identifiers, keys, file paths, protocol values |
| `OrdinalIgnoreCase` | case-insensitive keys, HTTP headers, file extensions |
| `CurrentCulture(IgnoreCase)` | text you show to and sort for a user |

```csharp
if (ext.Equals(".JPG", StringComparison.OrdinalIgnoreCase)) { }        // not ToLower() == ...
var set = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
```

`ToLower()` comparisons allocate two strings and depend on the current culture (the classic Turkish "i" bug: `"FILE".ToLower()` in Turkish culture isn't `"file"`). Also note that `IndexOf(string)`, `StartsWith(string)` and `CompareTo` use the **current culture** by default, unlike `Equals`, so pass `StringComparison` explicitly.
