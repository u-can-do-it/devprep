## Hints

- Is `z-index` compared globally across the whole page, or within some group?
- Which CSS properties besides `position` + `z-index` create a new group?
- How do modern dialogs and popovers escape this problem entirely?

## Answer

A **stacking context** is a group of elements that is painted as a single unit along the z-axis. `z-index` values are only compared **between siblings in the same stacking context**. Children can never escape their parent's context: a child with `z-index: 9999` inside a parent context with `z-index: 1` still sits below a sibling of that parent with `z-index: 2`.

```html
<div class="header" style="position: relative; z-index: 1">
  <div class="dropdown" style="position: absolute; z-index: 9999">...</div>
</div>
<main style="position: relative; z-index: 2">...</main> <!-- covers the dropdown -->
```

**What creates a stacking context** (common ones):

- The root `<html>` element.
- `position: relative/absolute` with a `z-index` other than `auto`; `position: fixed` or `sticky` always.
- A flex or grid **child** with a `z-index` other than `auto`.
- `opacity` below 1, `transform`, `filter`, `backdrop-filter`, `perspective`, `clip-path`, `mask`.
- `isolation: isolate`, `will-change` on any of the above, `contain: paint`, `mix-blend-mode`.

Also remember `z-index` does nothing on a statically positioned non-flex/grid item.

**Debugging & fixes:**

- Walk up the ancestors in DevTools looking for a property that creates a context (often an innocent `transform` or `opacity` animation).
- Render overlays near the root (a React **portal** into `document.body`).
- Use `isolation: isolate` on components to contain their internal z-indexes deliberately.
- Keep a small z-index scale in design tokens instead of escalating numbers.
- Use the native **top layer**: `<dialog>` opened with `showModal()` and the **Popover API** render above everything regardless of stacking contexts.

**Follow-up:** within one stacking context, paint order is: backgrounds, negative z-index, blocks, floats, inline content, `z-index: 0/auto` positioned elements, then positive z-index.
