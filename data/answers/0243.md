## Hints

- How could one layout render two independent pages side by side, each with its own loading and error state?
- How does Instagram show a photo in a modal on top of the feed, yet a full page if you refresh that URL?
- What does a slot render when the current URL doesn't match anything in it?

## Answer

**Parallel routes** let one layout render several pages at once using **named slots**. A slot is a folder starting with `@`, and it's passed to the layout as a prop:

```text
app/dashboard/
  layout.tsx       -> receives { children, analytics, team }
  page.tsx         -> children
  @analytics/page.tsx
  @team/page.tsx
```

Each slot gets its own `loading`/`error` boundaries and navigates independently. That's useful for dashboards, split views and conditional UI (e.g. render `@admin` or `@user` based on role). Since Next.js 16, every slot **must have a `default.tsx`**, which is rendered when the slot has no match for the current URL after a full load. Return `null` or call `notFound()` there.

**Intercepting routes** show a route **inside the current layout** during client-side navigation, while a direct visit or a refresh renders the normal page. The prefix works on **route segments**, not the file system: `(.)` same level, `(..)` one level up, `(..)(..)` two levels up, `(...)` from the root.

**Modal with a shareable URL:**

```text
app/
  layout.tsx                       -> renders {children} and {modal}
  @modal/default.tsx               -> return null
  @modal/(.)photos/[id]/page.tsx   -> <Modal><Photo/></Modal>  (soft navigation)
  photos/[id]/page.tsx             -> full photo page (direct visit, refresh)
  page.tsx                         -> feed with <Link href="/photos/1">
```

```tsx
'use client';
export function Modal({ children }: { children: React.ReactNode }) {
  const router = useRouter();
  return <dialog open onClose={() => router.back()}>{children}</dialog>;
}
```

Clicking a photo changes the URL to `/photos/1` and opens the modal over the feed. The URL is shareable, and refreshing shows the full page. Back closes the modal, and forward reopens it.

**Pitfalls:** a missing `default.tsx` (a build error in v16); a modal that stays open after navigating elsewhere (add a catch-all `@modal/[...catchAll]/page.tsx` returning `null`); and focus management or `Escape` handling for accessibility.

**Follow-up:** slots are not URL segments: `/dashboard/@team` isn't a URL.
