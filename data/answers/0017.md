## Hints

- Which fundamental object operations (get, set, delete, `in`, calling) could you intercept?
- Why do handlers usually forward to `Reflect.*` instead of doing `target[key]` themselves?
- Which popular libraries are built on top of Proxy?

## Answer

A **`Proxy`** wraps a target object. A **handler** defines **traps** that intercept fundamental operations: `get`, `set`, `has`, `deleteProperty`, `ownKeys`, `getOwnPropertyDescriptor`, `defineProperty`, `apply` and `construct` (for functions), and others.

**`Reflect`** has one method per trap, with the default behavior of that operation. Forwarding to `Reflect` keeps the semantics correct. It returns booleans instead of throwing, and it passes the right **`receiver`** so getters and inheritance work properly.

```js
function observable(target, onChange) {
  return new Proxy(target, {
    get(t, key, receiver) {
      const v = Reflect.get(t, key, receiver);
      return typeof v === 'object' && v !== null ? observable(v, onChange) : v;
    },
    set(t, key, value, receiver) {
      const ok = Reflect.set(t, key, value, receiver);
      if (ok) onChange(key, value);
      return ok; // returning false throws a TypeError in strict mode
    },
  });
}
const state = observable({ user: { name: 'Ann' } }, (k, v) => console.log(k, v));
state.user.name = 'Bob'; // logs: name Bob
```

**Real-world uses:**

- **Reactivity:** Vue 3, MobX, Valtio.
- **Immutable drafts:** Immer.
- **Validation and schema enforcement**, read-only views.
- **Logging, tracing, access control**, and auto-mocking in tests.
- **Default values, negative array indices**, and API clients that build URLs from property access.
- **Revocable access:** `Proxy.revocable`.

**Caveats:**

- **Invariants:** traps can't lie about non-configurable or non-writable properties. The engine throws a TypeError if they do.
- **Performance:** every intercepted operation pays extra overhead. Avoid proxies in hot loops.
- **Identity:** `proxy !== target`.
- **Internal slots:** built-ins with internal slots (`Map`, `Date`, private `#fields`) break when you call their methods through a proxy, because `this` is the proxy. Bind those methods to the target.
- **Shallow:** a proxy only intercepts its own object. Nested objects must be wrapped lazily, as in the example.

**Follow-up:** compare with `Object.defineProperty` getters and setters (Vue 2). Those can't detect added or deleted keys or array index changes.
