## Hints

- Which values take the element out of normal flow, and which leave its original space behind?
- What is an absolutely positioned element positioned relative to?
- What does a sticky element need before it can stick, and what can stop it?

## Answer

| Value | In normal flow? | Offsets (`top`/`left`/`inset`) are relative to | Typical use |
|---|---|---|---|
| `static` (default) | Yes | Offsets are ignored | Normal content |
| `relative` | Yes, and its original space is kept | Its own normal position | Small nudges; a containing block for absolute children |
| `absolute` | **No** | Nearest **positioned ancestor** (anything not `static`), or the initial containing block | Badges, overlays, icons inside inputs |
| `fixed` | **No** | The **viewport** | Sticky headers, floating buttons |
| `sticky` | Yes | Acts like `relative` until a scroll threshold, then sticks inside its scroll container | Table headers, section titles, sidebars |

```css
.card { position: relative; }
.card .badge { position: absolute; top: 0.5rem; inset-inline-end: 0.5rem; }

.toolbar { position: sticky; top: 0; }
```

**Why `sticky` often "doesn't work":**

1. **No threshold.** You must set `top`, `bottom`, `left` or `right`.
2. **An ancestor has `overflow: hidden`, `auto` or `scroll`.** That ancestor becomes the scroll container, so the element sticks inside it (often not at all) instead of the viewport. `overflow: clip` doesn't create a scroll container, so it's a safe alternative.
3. **The parent is too short.** A sticky element can't leave its parent. If the parent is as tall as the element, there's no room to stick.
4. **Flex or grid stretching.** In a flex row the item stretches to full height, so there's no room to move. Add `align-self: start`.

**`fixed` gotcha:** if any ancestor has `transform`, `filter`, `perspective`, `contain: paint` or `will-change: transform`, that ancestor becomes the containing block, and the "fixed" element scrolls with it.

All non-static positioned elements can take `z-index`, and `fixed`/`sticky` always create a stacking context.

**Follow-up:** prefer `transform: translate()` over changing `top`/`left` for animation, and use `inset: 0` as shorthand for all four offsets.
