## Hints

- How do you split 60 endpoints across files without a giant `main.py`?
- Where do you set shared prefixes, tags and auth for a group of routes?
- How do you turn domain exceptions like `OrderNotFound` into HTTP responses in one place?

## Answer

**Structure by feature (domain)**, not by technical layer, once the app grows:

```text
app/
  main.py              # create app, include routers, handlers, lifespan
  core/config.py, core/db.py, core/security.py
  orders/
    router.py          # HTTP layer only
    schemas.py         # Pydantic models
    service.py         # business logic, framework-agnostic
    repository.py      # DB access
    exceptions.py
  users/ ...
```

**APIRouter** groups routes and can carry a prefix, tags and dependencies:

```python
# orders/router.py
from fastapi import APIRouter, Depends
router = APIRouter(prefix="/orders", tags=["orders"],
                   dependencies=[Depends(require_user)])

@router.get("/{order_id}", response_model=OrderOut)
async def get_order(order_id: int, svc: OrderServiceDep):
    return await svc.get(order_id)          # may raise OrderNotFound

# main.py
app = FastAPI(lifespan=lifespan)
api = APIRouter(prefix="/api/v1")
api.include_router(orders.router)
api.include_router(users.router)
app.include_router(api)
```

**Exception handlers** keep HTTP concerns out of the service layer:

```python
class DomainError(Exception):
    status_code = 400
class OrderNotFound(DomainError):
    status_code = 404

@app.exception_handler(DomainError)
async def domain_error_handler(request: Request, exc: DomainError):
    return JSONResponse(status_code=exc.status_code,
                        content={"type": type(exc).__name__, "detail": str(exc)})
```

You can also override `RequestValidationError` and `StarletteHTTPException` handlers to give all errors one consistent shape (e.g. RFC 9457 problem details), and add a catch-all `Exception` handler that logs and returns a generic 500.

Principles: keep routers thin, put logic in services that receive dependencies (easy to unit-test), share dependencies via `Annotated` aliases, and version the API with a router prefix.

**Follow-up:** Handler matching uses the exception's class hierarchy. Which handler wins for a subclass? (The most specific registered class in the MRO.)
