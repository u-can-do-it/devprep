## Hints

- Does `:hover` create anything new, or does it describe a state of an existing element?
- How could you add a decorative icon before a link without changing the HTML?
- Why do some selectors have one colon and others two?

## Answer

A **pseudo-class** (single colon) selects an **existing element in a particular state or position**. A **pseudo-element** (double colon) targets a **part of an element**, or **generated content** that isn't in the DOM.

**Pseudo-classes:**

- User interaction: `:hover`, `:active`, `:focus`, `:focus-visible`, `:focus-within`
- Form state: `:checked`, `:disabled`, `:required`, `:invalid`, `:user-invalid` (only after the user has interacted), `:placeholder-shown`
- Structure: `:first-child`, `:last-child`, `:nth-child(2n+1)`, `:nth-of-type()`, `:empty`
- Logic: `:not()`, `:is()`, `:where()`, `:has()`
- Others: `:root`, `:target`, `:popover-open`, `:defined`

**Pseudo-elements:**

- `::before` / `::after`: generated content, which **requires** a `content` property
- `::placeholder`, `::marker` (list bullets), `::selection`, `::first-line`, `::first-letter`
- `::backdrop` (behind a modal `<dialog>` or fullscreen element), `::file-selector-button`, `::part()`, `::slotted()`

```css
.link:hover { text-decoration: underline; }               /* state */
li:nth-child(odd) { background: var(--stripe); }          /* position */
.required-label::after { content: " *"; color: crimson; } /* generated content */
input:user-invalid { border-color: crimson; }
```

**Details worth mentioning:**

- Old pseudo-elements (`:before`, `:after`) still work with one colon for backward compatibility. Write `::` in new code.
- In specificity, pseudo-classes count like classes (except `:where()`, which counts zero, and `:is()`/`:not()`/`:has()`, which take their argument's specificity). Pseudo-elements count like elements.
- `::before` and `::after` don't work on replaced elements such as `<img>` and `<input>`.
- Generated `content` **is** usually read by screen readers but can't be selected or copied. Don't put meaningful text there.

**Follow-up:** `:nth-child()` counts all siblings, while `:nth-of-type()` counts only siblings of the same tag. `:nth-child(2 of .item)` filters by a selector.
