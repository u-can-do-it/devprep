## Hints

- Which of these are already built into JavaScript today?
- What does `??=` do, and how does it shorten `groupBy`?
- How do `Set` and `Map` remove duplicates?
- What does `structuredClone` copy that `JSON.parse(JSON.stringify(x))` loses?

## Answer

> Most lodash helpers are a few lines of modern JavaScript, and some are now built in, like `Object.groupBy` and `structuredClone`. `groupBy` is a `reduce` into arrays, `uniqBy` uses a `Map` keyed by the value, `chunk` uses `Array.from` with `slice`, and `get` walks a path with optional chaining. For deep copies, `structuredClone` beats the JSON trick because it keeps `Date`, `Map` and `Set`. In an interview, mention the built-in, then write it yourself anyway.

Most lodash helpers are a few lines of modern JavaScript, and several are now built in.

```js
// groupBy: built in since ES2024 as Object.groupBy / Map.groupBy
const byRole = Object.groupBy(users, (u) => u.role);   // { admin: [...], user: [...] }

const groupBy = (arr, keyFn) =>
  arr.reduce((acc, item) => {
    (acc[keyFn(item)] ??= []).push(item);   // create the array the first time we see the key
    return acc;
  }, {});

// countBy: a frequency map, which is the most common hash-map interview step
const countBy = (arr, keyFn) => {
  const counts = new Map();
  for (const item of arr) counts.set(keyFn(item), (counts.get(keyFn(item)) ?? 0) + 1);
  return counts;
};

// uniq / uniqBy
const uniq = (arr) => [...new Set(arr)];
const uniqBy = (arr, keyFn) => [...new Map(arr.map((x) => [keyFn(x), x])).values()]; // keeps the last item per key

// chunk
const chunk = (arr, size) =>
  Array.from({ length: Math.ceil(arr.length / size) }, (_, i) => arr.slice(i * size, (i + 1) * size));

// pick / omit
const pick = (obj, keys) => Object.fromEntries(keys.filter((k) => k in obj).map((k) => [k, obj[k]]));
const omit = (obj, keys) => Object.fromEntries(Object.entries(obj).filter(([k]) => !keys.includes(k)));

// get by path: get(order, 'customer.address.city', 'n/a')
const get = (obj, path, fallback) => path.split('.').reduce((o, key) => o?.[key], obj) ?? fallback;

// sortBy without mutating the original
const sortBy = (arr, keyFn) =>
  arr.toSorted((a, b) => {
    const x = keyFn(a), y = keyFn(b);
    return x < y ? -1 : x > y ? 1 : 0;
  });

// small ones
const sum = (nums) => nums.reduce((total, n) => total + n, 0);
const range = (n) => Array.from({ length: n }, (_, i) => i);   // [0, 1, ..., n-1]
const isEmpty = (obj) => Object.keys(obj).length === 0;
```

**Deep clone:** `structuredClone(value)` is built in. It copies `Date`, `Map`, `Set`, typed arrays and circular references. It **throws** on functions and DOM nodes, and class instances come back as plain objects. `JSON.parse(JSON.stringify(x))` is worse: it turns `Date` into strings and drops `undefined`, `Map` and `Set` (#442).

**Strings:** sort with `a.localeCompare(b)` or `Intl.Collator`, and use `str.padStart(2, '0')`, `str.at(-1)` and `str.replaceAll()`.

**Debounce and throttle:** #12. **Memoize:** #167. **Deep equal:** #166.

**In an interview:** say "in production I'd use the built-in `Object.groupBy`", then write the `reduce` version anyway. It shows you know both.
