## Hints

- What layers surround the content of every element, from inside to outside?
- If an element has `width: 200px`, `padding: 20px` and a `2px` border, how wide is it on screen by default?
- Which layer is not included in the size even with `border-box`?

## Answer

Every element renders as a rectangular box made of four layers, from inside out:

1. **Content** — text, images, children.
2. **Padding** — space inside the border; takes the element's background.
3. **Border**.
4. **Margin** — transparent space outside the border, separating it from other elements.

**`box-sizing`** decides what `width` and `height` refer to:

- **`content-box`** (the default) — `width` is the content only. Padding and border are **added** on top: `200 + 2×20 + 2×2 = 244px` wide.
- **`border-box`** — `width` includes content + padding + border, so the element is exactly **200px**; the content area shrinks to 156px.

```css
*, *::before, *::after {
  box-sizing: border-box;
}
```

This global reset is near-universal because it makes layouts predictable: `width: 50%` plus padding no longer overflows its container. **Margin is never included** in either mode.

Related gotchas:

- **Margin collapsing:** vertical margins of adjacent block elements (or a parent and its first/last child) collapse into the larger one instead of adding up. It doesn't happen in flex or grid containers.
- Inline elements (`<span>`) ignore `width`/`height` and vertical margins.
- `outline` and `box-shadow` don't take up space in the box model.

**Follow-up:** DevTools' "Computed" panel shows the box model diagram — a good way to debug unexpected sizes.
