## Hints

- How do you track "who is inside right now" with O(1) lookups?
- How do you get all of one person's times together?
- Once one person's times are sorted, which times do you need to compare?
- `1059` to `1101` is 2 minutes, but `1101 - 1059 = 42`. What should you convert the times to first?

## Answer

Karat interviews usually give **one problem in 2–3 parts that build on each other**. Ask about the edge cases first, solve the easy part cleanly, then extend it.

**Part 1: who entered without exiting, and who exited without entering?**

```js
// records: [['Martha', 'exit'], ['Paul', 'enter'], ['Martha', 'enter'], ...]
function mismatchedEntries(records) {
  const inside = new Set();
  const noExit = new Set();
  const noEnter = new Set();

  for (const [name, action] of records) {
    if (action === 'enter') {
      if (inside.has(name)) noExit.add(name);   // entered twice in a row
      inside.add(name);
    } else {
      if (!inside.has(name)) noEnter.add(name); // exited without being inside
      inside.delete(name);
    }
  }
  for (const name of inside) noExit.add(name);  // still inside at the end of the day
  return [[...noExit], [...noEnter]];
}
```

This takes O(n) time and O(people) space.

**Part 2: who badged in 3 or more times within one hour? Return those times.**

The approach: **group by name → sort each person's times → sliding window.**

```js
// records: [['Paul', '1355'], ['Jennifer', '1910'], ['Paul', '1405'], ...]
const toMinutes = (hhmm) => {
  const t = String(hhmm).padStart(4, '0');
  return Number(t.slice(0, 2)) * 60 + Number(t.slice(2));
};

function frequentAccess(records, minCount = 3, windowMinutes = 60) {
  const byName = new Map();
  for (const [name, time] of records) {
    if (!byName.has(name)) byName.set(name, []);
    byName.get(name).push(time);
  }

  const result = {};
  for (const [name, times] of byName) {
    times.sort((a, b) => toMinutes(a) - toMinutes(b));
    let start = 0;
    for (let end = 0; end < times.length; end++) {
      // shrink the window until it spans less than an hour
      while (toMinutes(times[end]) - toMinutes(times[start]) >= windowMinutes) start++;
      if (end - start + 1 >= minCount) {
        // include every later time that still fits in this window
        let last = end;
        while (last + 1 < times.length && toMinutes(times[last + 1]) - toMinutes(times[start]) < windowMinutes) last++;
        result[name] = times.slice(start, last + 1);
        break;
      }
    }
  }
  return result;
}

frequentAccess([['Paul', '1355'], ['Paul', '1405'], ['Paul', '1450'], ['Paul', '1600'], ['Ann', '900']]);
// { Paul: ['1355', '1405', '1450'] }
```

**Complexity:** O(n log n) time for the sorting, plus O(n) for grouping and the window. O(n) space.

**What to say before you code:**

- Is "within one hour" inclusive? Is `1000` → `1100` within the hour? (The code above says no: the gap must be under 60 minutes.)
- Are the records sorted? Can times repeat? Do they cross midnight?
- Times are `HHMM` strings or numbers, so **convert to minutes** before subtracting.

**How it's scored:** a working, clearly named solution you can explain beats a clever one. Run your code on the given example, then add edge cases: an empty input, a single record, exactly 3 times, and a gap of exactly 60 minutes.
