## Hints

- What does a `ScrollView` do with 5,000 children?
- Which props tell `FlatList` that the user pulled down, or reached the end?
- What happens when you put a `FlatList` inside a vertical `ScrollView`?

## Answer

> `ScrollView` renders all its children at once, so use it for short, fixed content such as a form or a details screen. `FlatList` is virtualised: it renders only the rows near the viewport and unmounts the rest, so use it for any long or unbounded list. `SectionList` is the same idea with grouped data and section headers.

| | Renders | Use for |
|---|---|---|
| `ScrollView` | everything immediately | forms, articles, a handful of cards |
| `FlatList` | a window of rows | feeds, search results, chats, anything from an API |
| `SectionList` | a window of rows, grouped | contacts by letter, orders by date, with sticky headers |

A `.map()` inside a `ScrollView` works for 20 rows and falls apart at 2,000: slow first render and high memory use.

**A `FlatList` with the usual features**

```tsx
<FlatList
  data={orders}
  keyExtractor={(order) => order.id}
  renderItem={({ item }) => <OrderRow order={item} />}
  // pull-to-refresh
  refreshing={refreshing}
  onRefresh={onRefresh}
  // infinite scroll
  onEndReached={() => {
    if (hasNextPage && !isFetchingNextPage) fetchNextPage();
  }}
  onEndReachedThreshold={0.5}          // half a screen before the end
  ListFooterComponent={isFetchingNextPage ? <ActivityIndicator /> : null}
  // states and decoration
  ListEmptyComponent={<EmptyState text="No orders yet" />}
  ListHeaderComponent={<Filters />}
  ItemSeparatorComponent={Separator}
  contentContainerStyle={orders.length === 0 && { flexGrow: 1 }}
/>
```

**What to remember**

- `keyExtractor` must return a stable, unique string (an id, not the index). It works like `key` in React (#32).
- `onEndReached` can fire more than once, so guard it with a "loading" flag.
- The list itself needs a bounded height. Usually its parent has `flex: 1`.
- `FlatList` re-renders rows only when `data` changes by reference. If rows depend on something else (a selected id), pass it in `extraData`.
- Use `ListHeaderComponent` and `ListFooterComponent` for content above and below the rows. Don't wrap a `FlatList` in a `ScrollView` with the same direction: the list can't know its viewport, so it renders every row, and React Native warns "VirtualizedLists should never be nested inside plain ScrollViews".
- `numColumns` gives a simple grid, and `horizontal` gives a carousel.
- Rows that leave the window are unmounted, so local state inside a row (an expanded flag) is lost. Keep such state in the parent or a store.

**`SectionList`**

```tsx
<SectionList
  sections={[{ title: 'Today', data: todayOrders }, { title: 'Earlier', data: olderOrders }]}
  keyExtractor={(order) => order.id}
  renderItem={({ item }) => <OrderRow order={item} />}
  renderSectionHeader={({ section }) => <Text style={styles.header}>{section.title}</Text>}
  stickySectionHeadersEnabled
/>
```
