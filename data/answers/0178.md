## Hints

- How do you get the type of an existing variable or function without writing it out again?
- What does `keyof` return for an object type?
- How would you type a `get(obj, key)` function so that the return type depends on the key?

## Answer

These three operators let you **derive** types from other types or values instead of duplicating them:

- **`typeof value`** (in a type position) gives the type of a runtime value.
- **`keyof T`** gives the union of `T`'s keys.
- **`T[K]`** (indexed access) gives the type of property `K` of `T`. `T[number]` gives an array's element type.

```ts
const config = { port: 3000, host: 'localhost', debug: false };

type Config = typeof config;        // { port: number; host: string; debug: boolean }
type ConfigKey = keyof Config;      // 'port' | 'host' | 'debug'
type Port = Config['port'];         // number
type Value = Config[ConfigKey];     // number | string | boolean

function get<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
const p = get(config, 'port');      // number
// get(config, 'nope');             // error
```

**Common combinations:**

```ts
type Handler = typeof handleRequest;               // a function's type
type Params = Parameters<typeof handleRequest>[0]; // its first parameter
type Item = (typeof items)[number];                // array element type
type User = Awaited<ReturnType<typeof fetchUser>>; // resolved async result
```

**Gotchas:**

- `keyof` of a type with a string index signature (`Record<string, X>`) is `string | number`, because numeric keys are allowed too.
- `keyof` can include `symbol`. Use `K & string` or `Extract<keyof T, string>` when you need string keys only, for example in template literal types.
- `typeof` in a type position only works on identifiers and property paths, not on arbitrary expressions.

These are the building blocks of mapped and conditional types, such as `{ [K in keyof T]: ... }`.
