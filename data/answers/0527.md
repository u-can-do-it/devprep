## Hints

- Which array methods return a copy instead of mutating, and when did they arrive?
- How did you group an array by a key before `Object.groupBy` existed?
- What does `using` do at the end of a block, and which other language has the same idea?

## Answer

Interviewers ask this to see whether you keep up and whether you know what is safe to use without a polyfill. Group the features by what they replace.

**ES2023**

- Non-mutating array copies: `toSorted`, `toReversed`, `toSpliced`, `with(index, value)`. They replace `[...arr].sort()` and make React state updates obvious (#162, #199).
- `findLast` / `findLastIndex`: search from the end without `reverse()`.
- Symbols as `WeakMap` keys, hashbang (`#!`) lines in scripts.

**ES2024**

- `Object.groupBy(items, fn)` and `Map.groupBy` replace the `reduce` idiom (#516).
- `Promise.withResolvers()` returns `{ promise, resolve, reject }`, handy for bridging callbacks or events to promises (#441).
- RegExp `v` flag: set operations and string properties in character classes (`/[\p{L}--[a-z]]/v`).
- Resizable `ArrayBuffer` and `ArrayBuffer.prototype.transfer`, `Atomics.waitAsync`.
- `String.prototype.isWellFormed` / `toWellFormed` for lone surrogates.

**ES2025**

- Set methods: `union`, `intersection`, `difference`, `symmetricDifference`, `isSubsetOf`, `isSupersetOf`, `isDisjointFrom` (#156).
- Iterator helpers: `.map`, `.filter`, `.take`, `.drop`, `.flatMap`, `.reduce`, `.toArray`, `.some`, `.every`, `.find`, `.forEach` on any iterator, plus `Iterator.from`. They are lazy, so you can process a generator or a huge `Map` without building intermediate arrays (#15).
- `Promise.try(fn)`: start a chain from a function that may throw synchronously or return a promise.
- JSON modules with import attributes: `import data from './x.json' with { type: 'json' }`.
- RegExp duplicate named groups in alternatives and inline modifiers `(?i:...)`.
- `Float16Array`, `Math.f16round`.

**Finalized or shipping in all engines in 2025-2026** (check caniuse or node.green for your targets):

- `Array.fromAsync(asyncIterable)`: the async counterpart of `Array.from` (#169).
- Explicit resource management: `using` and `await using` call `[Symbol.dispose]` / `[Symbol.asyncDispose]` when the block exits, like C#'s `using` or Python's `with` (#75). `DisposableStack` composes several resources.
- `Error.isError`, `Math.sumPrecise`, `Uint8Array.fromBase64` / `toBase64` (no more `btoa` on binary strings).
- Temporal reached Stage 4 in March 2026 (ES2026); Firefox and Chromium ship it, Safari lagged, so iOS still needs the polyfill (#172).

**How to answer in an interview:** name three or four you use daily with a concrete win (immutable updates, `groupBy`, Set operations), state what your toolchain does about the rest (TypeScript targets, Babel or esbuild only transpile syntax, built-ins need polyfills such as core-js, #460), and be honest about what is still a proposal.

**Follow-up:** does `toSorted` do a deep copy? (No, it is a shallow copy of the array; elements are the same references.)
