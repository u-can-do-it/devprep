## Hints

- If you described this image to someone over the phone, what would they actually need to know?
- What does a screen reader announce for an `<img>` with no `alt` attribute at all?
- Does an image inside a link describe the image, or where the link goes?

## Answer

`alt` provides the **text alternative** that screen readers announce. It's also shown when an image fails to load, and used by search engines. Good alt text depends on the image's **purpose in context**, not on what it looks like.

**Informative images:** describe the information they carry, concisely.

```html
<img src="chart.png" alt="Revenue grew 40% from Q1 to Q4 2026">
```

**Decorative images:** use an **empty `alt=""`** so screen readers skip them entirely (backgrounds, flourishes, an icon next to text that already says the same thing).

```html
<img src="divider.svg" alt="">
```

**Never leave `alt` out.** With no `alt` attribute, many screen readers read the **file name** ("IMG underscore 4032 dot jpeg").

**Functional images** (inside a link or button): describe the **action or destination**, not the picture.

```html
<a href="/"><img src="logo.svg" alt="Acme home"></a>
<button><img src="trash.svg" alt="Delete draft"></button>
```

**Images of text:** the alt must contain the same text. Better still, use real text.

**Complex images** (charts, diagrams, maps): give a short alt plus a longer description nearby, such as a caption, a data table or a "Text description" disclosure. `<figure>` with `<figcaption>` works well.

**Writing tips:**

- Don't start with "Image of" or "Picture of". The screen reader already says "image".
- Don't repeat surrounding text. If the caption already describes it, the alt can be shorter or empty.
- Keep it short: usually one sentence. Include text that appears in the image if it matters.
- Context changes the answer: the same photo of a CEO might be "Jane Doe, CEO" on a team page and empty next to her quote with her name.

**Other image types:**

- Inline SVG: `role="img"` with `aria-label`, or a `<title>`.
- Decorative SVG: `aria-hidden="true"`.
- CSS background images have no alt, so never use them for meaningful content.
- AI-generated alt text is a starting point, not a final answer. It describes appearance, not purpose.

**Follow-up:** lint for it with `eslint-plugin-jsx-a11y` (`alt-text`) and axe. Missing alt is one of the most common WCAG failures.
