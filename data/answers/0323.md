## Hints

- Where does FastAPI get the information to describe your endpoints?
- What can frontend or mobile teams generate from `/openapi.json`?
- How would you hide the docs in production or group endpoints by feature?

## Answer

FastAPI builds an **OpenAPI 3.1 schema** from your code: paths, methods, parameters, Pydantic models (as JSON Schema), status codes and security schemes. It serves:

- **`/openapi.json`**: the machine-readable schema.
- **`/docs`**: interactive **Swagger UI**, where you can try requests and authorize with a token.
- **`/redoc`**: ReDoc reference documentation.

Because the docs come from type hints and models, they **stay in sync with the code**.

Customization:

```python
from fastapi import FastAPI

app = FastAPI(
    title="Orders API",
    version="2.3.0",
    summary="Order management for the shop",
    openapi_tags=[{"name": "orders", "description": "Create and track orders"}],
    docs_url="/docs" if settings.show_docs else None,   # disable in prod
    redoc_url=None,
)

@app.post(
    "/orders",
    tags=["orders"],
    summary="Place an order",
    response_model=OrderOut,
    status_code=201,
    responses={409: {"model": ErrorOut, "description": "Duplicate order"}},
    operation_id="createOrder",
)
async def create_order(order: OrderIn): ...

@app.get("/internal/metrics", include_in_schema=False)
async def metrics(): ...
```

- Add examples with `Field(examples=[...])` or `model_config = {"json_schema_extra": ...}`.
- Use `deprecated=True` on routes and `Field(description=...)` on model fields.
- Stable **`operation_id`s** (or `generate_unique_id_function`) produce clean names when generating TypeScript clients with tools like `openapi-typescript` or `orval`.
- Full control: override `app.openapi()` to post-process the schema.

**Follow-up:** Is hiding `/docs` a security measure? (No. It reduces exposure, but every endpoint must still enforce auth.)
