## Hints

- What do the four principles behind WCAG stand for?
- Which conformance level do laws and contracts usually require?
- Does large, bold text need the same contrast as body text? What about icons and input borders?

## Answer

**WCAG** (Web Content Accessibility Guidelines) is the W3C standard for accessible web content. The current version is **WCAG 2.2** (2023), and it's backwards compatible with 2.1 and 2.0. It's organized around four principles, **POUR**:

- **Perceivable:** text alternatives, captions, contrast, content that reflows
- **Operable:** keyboard access, enough time, no seizure triggers, navigable
- **Understandable:** readable, predictable, helps users avoid and fix errors
- **Robust:** works with assistive technology (valid names, roles and values)

Each guideline has testable **success criteria** at three levels:

- **A:** the bare minimum. Without it, some users are completely blocked (keyboard access, alt text).
- **AA:** the **standard target** referenced by most laws and procurement rules. Includes contrast, resizing text, visible focus, and consistent navigation.
- **AAA:** the strictest. Not required for whole sites, because some criteria can't be met for all content.

**Legal context:** the **European Accessibility Act** (in force since June 2025) and US rules (ADA, Section 508) all point to **WCAG AA**.

**Color contrast (ratio from 1:1 to 21:1):**

| Content | AA | AAA |
|---|---|---|
| Normal text | **4.5:1** | 7:1 |
| Large text (≥ 24px, or ≥ 18.66px bold) | **3:1** | 4.5:1 |
| UI components and meaningful graphics (input borders, focus rings, icons, chart lines) | **3:1** (1.4.11) | n/a |

Also: **don't use color alone** to convey meaning (1.4.1). An error needs an icon or text, and a link in body text needs an underline or another cue. Disabled controls and pure decoration are exempt from the contrast rules.

**New in 2.2 (selection):** Focus Not Obscured, Target Size Minimum (**24×24 px**), Dragging Movements (offer a non-drag alternative) and Accessible Authentication (allow paste and password managers).

**Follow-up:** WCAG 3.0 is still a draft. APCA, a perceptual contrast model, is being explored for it, but **WCAG 2.2 AA is what's legally relevant** today.
