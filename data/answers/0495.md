## Hints

- What does `T extends U ? X : Y` do when `T` is a union and appears "naked" (not wrapped)?
- What is `keyof (A | B)`: all keys, or only the shared ones?
- How do you stop a conditional type from distributing?

## Answer

> When a conditional type checks a bare type parameter, TypeScript applies it to each member of a union separately and joins the results. That's how `Exclude` and `Extract` work, and wrapping both sides in a tuple turns it off. `Omit` is not distributive: it's built on `keyof` of the whole union, which keeps only the shared keys, so a discriminated union collapses into one object type. A `DistributiveOmit` helper fixes this by applying `Omit` to each member.

A conditional type **distributes over a union** when the checked type is a bare type parameter. TypeScript applies it to each member separately and joins the results:

```ts
type ToArray<T> = T extends unknown ? T[] : never;

type A = ToArray<string | number>; // string[] | number[]  (not (string | number)[])
```

This is how `Exclude` and `Extract` work:

```ts
type Exclude<T, U> = T extends U ? never : T;
type B = Exclude<'a' | 'b' | 'c', 'a'>; // 'b' | 'c'
```

**Turning distribution off:** wrap both sides in a tuple, so `T` is no longer bare:

```ts
type IsString<T> = T extends string ? true : false;
type C = IsString<string | number>;   // boolean  (true | false)

type IsStringStrict<T> = [T] extends [string] ? true : false;
type D = IsStringStrict<string | number>; // false
```

Also, a distributive conditional type applied to `never` gives `never` (an empty union has no members to map). Use `[T] extends [never]` to check for `never`.

**Why `Omit` breaks discriminated unions:** `Omit` is a mapped type, not a distributive conditional type, and `keyof (A | B)` contains only the keys **shared** by every member:

```ts
type Shape =
  | { kind: 'circle'; id: string; radius: number }
  | { kind: 'square'; id: string; size: number };

type NoId = Omit<Shape, 'id'>;
// { kind: 'circle' | 'square' }: radius and size are gone, and it's no longer a union
```

The fix is a distributive version:

```ts
type DistributiveOmit<T, K extends PropertyKey> = T extends unknown ? Omit<T, K> : never;

type NoId2 = DistributiveOmit<Shape, 'id'>;
// { kind: 'circle'; radius: number } | { kind: 'square'; size: number }
```

The same issue affects `Pick` and anything built on `keyof` of a union. It comes up often with React props that are discriminated unions (for example `Omit<ButtonProps, 'onClick'>` on a polymorphic button).
