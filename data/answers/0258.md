## Hints

- After you draw a shape on a canvas, can you attach a click handler to that shape?
- What happens to each approach when you have 50 elements, then 50,000?
- Which one stays sharp when zoomed, and which one is accessible to screen readers by default?

## Answer

**SVG** is **retained-mode** vector graphics. Every shape is a DOM element:

- It stays sharp at any zoom level or pixel density.
- Each shape can be styled with CSS, animated, and given event listeners (`circle.addEventListener('click', ...)`).
- It can be accessible: `<title>`, `role="img"`, `aria-label`, and real text that's selectable.
- Cost grows with the number of nodes. Thousands of elements mean a large DOM and slow style, layout and paint.

**`<canvas>`** is an **immediate-mode** bitmap. You issue draw calls and the browser keeps only the pixels:

- It handles very large numbers of objects and per-frame redraws: games, particle effects, heatmaps, image editing, big charts.
- There are no per-shape events. You do your own hit-testing from mouse coordinates.
- You must handle device pixel ratio yourself or it looks blurry. Scale the backing store by `devicePixelRatio`.
- It's opaque to assistive technology. Provide a text alternative or fallback content inside the `<canvas>`.

```js
const canvas = document.querySelector('canvas');
const dpr = window.devicePixelRatio || 1;
canvas.width = canvas.clientWidth * dpr;
canvas.height = canvas.clientHeight * dpr;
const ctx = canvas.getContext('2d');
ctx.scale(dpr, dpr);
ctx.fillRect(10, 10, 100, 50);
```

**Choosing:**

| Use SVG | Use canvas |
|---|---|
| Icons, logos, illustrations | Games, simulations |
| Charts with up to a few thousand marks and interactive tooltips | Charts with tens of thousands of points |
| Diagrams that need CSS styling and accessibility | Image or video pixel processing |

For heavy 3D or GPU work, use **WebGL** or **WebGPU** on a canvas. **`OffscreenCanvas`** lets you render inside a Web Worker. Many charting libraries switch from SVG to canvas once the data gets large.

**Follow-up:** inline SVG can be styled with `currentColor` so icons follow the text color.
