## Hints

- Is the thing you're centering text, a block with a known width, or an element of unknown size?
- What can a flex or grid container do for its children that a plain block can't?
- Which technique still works when the element must be layered over other content?

## Answer

**Grid** is the shortest way to center both axes:

```css
.parent { display: grid; place-items: center; }
```

**Flexbox:**

```css
.parent { display: flex; justify-content: center; align-items: center; }
```

Or, from the child's side: `.parent { display: flex } .child { margin: auto; }`.

**Absolute positioning**, for overlays and modals over other content:

```css
.parent { position: relative; }
.child {
  position: absolute;
  inset: 0;
  margin: auto;      /* centers if the child has a defined width/height */
  width: fit-content;
  height: fit-content;
}

/* Unknown size, classic version */
.child { position: absolute; top: 50%; left: 50%; translate: -50% -50%; }
```

Translate offsets can land on half pixels, which blurs text slightly.

**Horizontal only:**

- Inline content: `text-align: center` on the parent.
- A block with a width: `margin-inline: auto` (`margin: 0 auto`).

**Vertical only, modern:** `align-content: center` now works on regular **block** containers, not just flex and grid, so you don't need to change `display`.

**Single line of text:** `line-height` equal to the height works but is brittle. Prefer flex or grid.

**Pitfalls:**

- Centering inside a parent with no height does nothing vertically. Give it height (`min-height: 100dvh` for full screen).
- A centered element taller than its container can overflow above the top where it can't be scrolled to. `align-items: safe center` avoids this.

**Follow-up:** for a full-screen modal, the native `<dialog>` is centered by default in the top layer.
